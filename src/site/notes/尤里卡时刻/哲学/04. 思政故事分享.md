# 企业知识数字化实践

## 背景介绍

潘玲：云轴科技中英文文档总负责人，深耕云计算IaaS领域。

云计算包含三层：
+ SaaS（软件即服务）：提供可直接使用的完整软件应用，用户只需登录即可使用；
+ PaaS（平台即服务）：提供应用开发、运行和管理的平台，如操作系统、中间件、数据库，如Docker容器等
+ IaaS（基础设施即服务）：提供云端的虚拟服务器、存储和网络资源。

ZStack 做的事情是把**物理的 Infra（服务器、存储、网络）** 通过软件（云操作系统）变成**虚拟的、可自助服务的 Infra（云平台）**。
## 自己的价值

在AI时代，自己作为知识工作者的价值在哪里？从个人、社会（时代的势）、企业（行业机遇）三者框架中去思考

+ 宏观背景叙事：新质生产力，数字经济；
+ 行业变局：企业知识管理从“支撑职能”像“战略资产”演进；数据->信息->知识->智慧
+ 个人思考：AI浪潮中如何不被替代，借势升级，如何从执行者成长为变革推动者？

## 企业产品

+ ZStack文档DevOps平台：传统方式下，产品文档的编写、排版、格式转换、多版本发布等流程非常耗时，且容易出错，尤其是在产品版本快速迭代时，文档很容易滞后。该平台将文档当作代码进行管理：模块化、版本管理、自动化生成HTML/PDF。
+ ZStack AI翻译平台：数据整理->模型选择->LLM精调->质量评估->持续迭代


> [!NOTE] DevOps
> DevOps 的核心思想就是通过**自动化工具链**和**协作文化**，将开发、测试、部署、运维等环节串联成一个流畅的循环，即“**持续集成、持续交付、持续部署**”的流水线。


## AI对个人影响的思考

潘同学是乐观主义，认为在AI时代，个人不会被替代，反而是一个升级的机会。在24年有AI冲击苗头的时候就开始在准备转换方向了。

老师是悲观看法：
+ 虽然AI对他影响较小（有人用Claude训练了研究生，发了一篇文章），但是自己孩子会有影响；
+ 企业辞退老员工的动机会更大；
+ 一个成熟的行业应该是能够给每一个人基本的体面；
+ 意味着头脑里的知识不再重要了；


# 港珠澳大桥

马忠同学，物流MEM学院。

## 难点

+ 伶仃洋主航道要保障30万吨级的巨轮通航，要求把桥建宽了；
+ 港珠澳有很多机场，要求桥梁限高<120米；
+ 珠海侧淤泥很多，河床很软，对隧道施工不友好；

## 方案

### 全桥方案

没有办法建造高度在80米以下，满足这么大的通航要求；

### 全遂方案
成本高，河床条件限制；

## 桥、岛、隧结合方案

最终方案：珠海到西岛、东岛到深圳区段建桥，西岛和东岛之间用隧道（建了一个人工岛）；采用的方案是将钢圆筒直接固定并插入海床，待所有钢圆筒按规划完成安插后，再向筒内回填土方。

# 商飞编队

朱逸凡，航空MEM学院，做模拟器飞行仿真

C909、C919三机编队，为了展示实力。编队距离在几十米，飞机尾流影响，大飞机机动性低，对飞行员的操作要求非常高，需要在模拟器上一周要练6天，每天8小时，形成肌肉记忆。
