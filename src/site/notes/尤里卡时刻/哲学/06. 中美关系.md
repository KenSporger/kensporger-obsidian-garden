# 修昔底德陷阱

哈佛大学教授艾利森（Allison）提出**修昔底德陷阱**概念：当一个崛起国家对守成大国形成战略威胁时，双方极易滑向冲突与战争。

**经典案例：雅典城邦对斯巴达的威胁**

- **背景**：在击败波斯入侵后，雅典实现了快速复兴，实力大幅提升，对斯巴达构成了显著战略压力。尽管如此，双方当时仍签订了三十年和平合约。
- **导火索**：斯巴达的盟友科林斯，与中立城邦科西拉爆发战争，科西拉随即向雅典求援。
- **结构性压力**：双方均陷入无解的战略两难。对雅典而言，援助科西拉便会违反三十年合约；若拒绝援助，斯巴达的势力则会进一步扩张。而斯巴达同样面临困境：支持科林斯会直接陷入战争泥潭；保持中立，又会丧失在盟友中的权威，还会将战略主动权拱手让给雅典。
- **结果**：科西拉对双方本都不具备核心战略价值，可两国却被迫卷入战争。最终雅典战败，斯巴达也自此开始走向衰落。

艾利森统计了历史上陷入修昔底德陷阱的十六次案例，其中仅有四次成功避免了战争。据此他认为，中美同样有机会规避战争，关键在于深入研究这四次未爆发战争的核心原因。
- 教会权力凌驾于世俗皇权之上，由教会在两国之间居中斡旋调停；
- 英国与美国：作为守成国的英国主动做出战略让步，将阿拉斯加相关权益移交美国（美国原为英国殖民地，彼时英国核心竞争目标是德国，因此通过让渡美洲控制权来拉拢美国）；
- 古巴导弹危机：核威慑的存在，使得美苏双方均不敢轻易动用武力。
