# 从小镇做题家到创业者

大伟哥在本科时代是平平无奇的“小镇做题家”：卷GPA、不参加社团、泡图书馆。回过头看，他觉得自己大学的生活一点也不精彩，浪费了认识很多优秀同学的机会。

2008年，经济危机，导致无法申请出国。所幸，最终能够保送交大研究生，也提前进了实验室。但逐渐认识到自己不是做科研的料，于是做了个改变人生轨迹的决定——在最短的时间完成毕业最低要求，不卷课程和科研，最终在研一下达到了毕业标准。通过这样的方式，获得了大量的时间，可以频繁地去和各种交大人接触，打开了自己的视野。

他发现，这些“非典型”交大同学有的在开淘宝店，有些在帮别人炒股，一个月能挣几万块钱。然后，在学长的怂勇下，大伟哥决定跟随他们去深圳创业。但一帮人浑浑噩噩干了三个月没啥产出，遂打算回交大继续申请出国。就在这个时候，蔡浩宇跟一些技术同学一起做项目有理念冲突，所以想请大伟哥一起创业，让他做技术之外的事。大伟哥觉得蔡浩宇非常靠谱就答应了，之后就诞生了米哈游。

大伟哥回顾这段经历，感慨道：**人生是一个探索的过程，很多时候都没法一下子看清前面的路，在选择时候想要价值最大化是基本不可能的；但是，每当感受到命运选择了自己的时候，不要畏惧接受，去尽最大努力做好眼前的事情，最后所有的点都会连成线**。

那么，在AI时代，我们如何对抗焦虑呢？大伟哥给出了三点建议。

# 寻找热爱

外部环境有很多不确定的因素，比如哪个专业会成为时代的主流、哪个方向会成为未来等等。但只有一件事情是可控的，那就是**你到底想做什么样的事情，想成为一个什么样的人**。当然要找到这个问题的答案确实非常得难，但还是**应该努力去想一想**。

大伟哥谈到蔡浩宇，他有一句slogen叫“技术宅拯救世界”。不管米哈游发展地多么壮大，他都会在一线做技术，学习新的东西（比如AI），坚持了15年，每天生活得很有期待感。**这个就是热爱，就是人生最好的状态**。

所有很多**功利的东西**，像科研成果、高薪资的工作都像是一个结果，这些东西不由自己掌控，如果一定要追求这个东西，就会带来巨大的焦虑。

总之，有一个自己想做的事情，就不会焦虑，就能够对抗周期。

# 立即行动

很多时候我们焦虑，其实是因为自己**没有在做具体的事情**。所以，如果想做一个事情，或者有一个目标，那就**马上去行动**。大部分人的焦虑其实都来自于**想得太多而行动不足**。

我们成绩好的同学有一个很大的缺点，就是**优绩主义**，什么事情都想一开始就做得很好，就会有很大的压力，思来想去的，不敢去做这件事情。

有一句很平实的话，叫“出来混，最重要的是什么？是出来这件事情”。做一件目前还不擅长的事件，**最重要的不是去学会他，最重要的是先去做**，先做个10分，然后20分，30分...可能做了一段时间后，会发现当初想的事情跟最后的时候是天差地别的。

拿米哈游来说，2011年的时候，没有主流VC投他们，因为当时做的是平凡的东西，并不独特。但是最后为什么成功了呢？因为他们开始做了，并且每次做的都比原来更好一点。**所谓伟大的事业，它的起点都是非常非常粗糙的。**

# 以终为始

有些人有了自己想做的事，也有很强的执行力。但是为什么还是迟迟的没有去做事情呢？本质上是出于**对未知不确定性的恐惧**。而要对抗这种不确定的恐惧，就要做**倒推和拆解**——你要完成这个目标大概有多少步？最重要的事有哪些？每一步预计多久才能完成？即以终为始。

# 总结

如果说，针对想做什么样的事情，想成为一个什么样的人这个问题，目前没有一个百分之百确定的长远设想。没有关系，那就从短期的一个目标出发，做倒推、拆解和进度量化，然后马上行动。在这个过程中，自然会产生新的目标，甚至找到那个问题的确切答案（关键要坚持不断地去想这个问题，去思考当前这个目标是不是自己真正想要的。

因为最近正好在找工作，听了这个分享感触颇深。在DJI提出离职的那段时期，可以说自己对于“想做什么样的事情，想成为一个什么样的人”思考了很多，当然最后也没有找到答案——不过萌生了像“去当农业飞手”这样离谱的想法，并且当时真的立即去行动了，结果验证现实和自己想的有极大偏差，不过没有关系，因为那段时间自己像打了鸡血一样，对未来充满期待，回想起来也是挺美好的。

说回到求职面试上来，这一次也算是放下一点“完美主义”，不会想着先把知识点、项目补齐了再去接面试，而是前期找一些不太看重的企业边面边查漏补缺，三四家流程走下来，基本上对付大部分面试官都游刃有余了。

至于焦虑情绪，在面试前期一段时间挺重的，主要去年离职后AI编程能力大大增强了，自己都没有接触过Cursor、Claude Code这些工具，另外也是在AI冲击软件行业趋势下，对自己的职业发展感到悲观和迷茫。但随着自己去学习接触这些编程工具，以及AI工程的知识，这些焦虑情绪也被知识获取带来的满足感所缓解。

这两天其实最主要的纠结在于，面了傅利叶和它石智航的机器人工程师，二面都过了，下周安排了HR面。但是傅利叶是机器人[系统研发工程师](https://zhuanlan.zhihu.com/p/1929261502835167289)，对机器人全栈能力要求高（要花很多时间去补技术栈），职业发展更偏向于技术广度——硬件、结构、算法、软件都得了解，但结果就是样样做不深，而且可能还需要频繁沟通协调，会比较累（身体上和心理上）；好处在于工作内容和目前的工程管理专业非常契合，一些质量体系建设非常适合拿来做课题（借此能比较好地利用学校资源），对具身智能有比较全面的了解（甚至会接触产线、供应链）。它石的话就是做机器人软件开发，更专一点。

此外，自己也能选择去闵行校区附近的穹彻智能这种小厂，工作节奏975，下了班能练练乐器或者DIY一些机器人项目（比如钢琴机器人），就是薪资要砍一半，要接受这种心理落差也挺不容易的...
