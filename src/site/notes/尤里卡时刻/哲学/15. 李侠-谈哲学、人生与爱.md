# 人生意义

以前的人通过与家族的人交流获得意义感，但工业革命之后，变成了小家，人变成了消费意义的动物，西方人可以通过宗教来获得意义。

世界观决定意义的生产规模与效率，下面三个维度都是可以获取意义的：
+ 真理之维：真、假，生存之法；
+ 伦理之维：处理人与社会、自然的关系，中华优秀的传统文化（儒释道）；
+ 审美之维：社会分工后，心理问题的人比农业时代更多，所以要强调人对自我的关怀；
三个维度综合起来形成认知视界，即格局。

0-30岁是儒学指导的，知其不可为而为之，要奋斗改变世界（入世）；到40岁则是道家指导的，意识到改变世界不可能，于是独善其身（出世）；50岁，到了知天命，信仰佛（弃世）。

推广中国优秀传统文化，要批判文化复兴，近50年是中华5千年最好的社会了，不能倒退回去，要向前走，不要回头看。历史的进步不是必然的，是大部分人扛住基本面，少数人推动上一层次的。


# 哲学

哲学包含三大方面：本体论、认识论、**价值论（美学+伦理学）**。

从这三个方面看西方人和中国人的差别：本体论和认识论都是一样的（都知道牛顿定理），差别在于价值论。

马哲的方法论只是认识论的一部份，不足单独以支撑起哲学的大厦。


# 爱

+ Eros：情爱，代表感性冲动以及浪漫的情怀；
+ Philia：代表一种友爱，温和而理性；
+ Agape：代表一种博爱，没有任何差别；

母爱剥夺和社会隔离实验，论文《The nature of love》（爱的本质）提出爱由**触摸、运动、玩耍**构成，而非单纯喂养。
+ 彻底否定斯金纳 "强化 - 奖惩" 理论对亲子关系的简化解释
+ 证明非物质需求（情感、安全）比物质需求更基础
+ 影响了孤儿院、医院新生儿护理的理念

《爱的三角理论：亲密、激情与承诺》提出了爱的八种形式：

|8|冷漠疏离的家族式利益关系|×|×|×|只剩血缘与利益捆绑，无爱意、无心动、无相守意愿，毫无情感联结，形同陌路|无爱|

[我们爱什么](https://blog.sciencenet.cn/blog-829-1518959.html)：
+ 变灭无常的事物：钱、权利，会患得患失；
+ 非变灭无常的事物：荣誉、尊严、信任、人格；
+ 由于自己的力量而永恒的事物：大道；


爱产生于我们对一个事物的认识，事物越伟大和崇高，我们的爱也越强烈。摆脱爱的方式：通过对一个更美好的事物的认识；或者是通过经验（用亲身经历打破已有的认知）。
