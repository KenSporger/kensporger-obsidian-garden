# 自然辩证法

辩证法，Dialectic，最早来自苏格拉底对话录。在两人的对话中，基于相同的意义系统、推论原则，对某个话题不同看法进行有效地沟通，形成共识，最终得到**真理**（辩证法的目标）。

两个人之间讨论不在场的第三人，一定会形成对第三人的误解，这是现实生活中常见的现象。

形而上学：事物、现象背后不变的本质和原因，和万物永恒发展的观点对立。形而上学并非是错误的，世界既有变的东西，也有不变的东西。

辩证法基于四个原则：
+ 具体事物是有限和短暂的，但是真理、想法是长久甚至永恒的（如相对论、李白）；
+ 任何事物都是矛盾对立统一的；
+ 量变引起质变；
+ 发展是螺旋上升的；

劳动创造价值，价值使得人自由，但是发现人工作创造了价值，但是自由并没有增加，劳动者反而被锁在了工作上。

任何社会的进步[[尤里卡时刻/哲学/15. 自然辩证法-谈哲学、人生与爱#^376a86\|不是必然的]]，都是在血肉和苦难之上的：在拿破仑攻打普鲁士王国时，黑格尔表示欢迎，可以推动普鲁士从封建走向共和政体，鸦片战争也是如此。


现象->正题->反题->合题。
+ 正题：主观、带个人偏见的；
+ 反题：客观的，带时代偏见的；
+ 合题：绝对精神，真理；

自然辩证法，主要关注自然界的规律，与之相对的是历史辩证法。
