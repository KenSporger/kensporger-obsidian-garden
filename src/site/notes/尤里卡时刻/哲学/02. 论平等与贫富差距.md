# 当今世界的贫富差距


乐施会2019年数据表明，全球最富有的26人拥有与世界上最贫穷的一半人口（38亿人）相等的财富，而且这个差距在逐年增大，最贫穷的人减少的财富流转到了富人增加的财富中。

贫富差距的扩大有两种情况：
+ 穷人的财物也在增加，并且生活境遇逐年改善，解决了温饱问题，这样很少有人会在意这个差距；
+ 穷人的财物减少了，生活境遇下降，贫富差距就会成为很显著的问题。

乐施会的数据反映的是第二种情况。现实情况与中国传统文化宣扬的“劫富济贫”观念相反。

# 中国的贫富差距

2023年，中国千万资产家庭208万户，亿元资产家庭13.3万户，然而低收入群体占到几亿。中国要拉动消费不能靠这些富人，而是中低收入群体。


# 贫富差距的原因

基于课上同学投票结果：运气>家庭>社会环境>个人努力。这个统计结果非常典型，唯一能够掌控的“勤奋”被认为不重要，如果真的是这样，意味着贫民阶层将无法实现跃升。

我投的票为：家庭>个人努力>运气。一方面我能看到原生家庭给予我的局限性，另一方面自己比同样背景的人走得会更远一些，这是work hard以及luck的因素。至于社会环境，大家都处在同样的社会时代，可以说都差不多。

## 什么是命

课堂上有同学提出“命”也是一个因素，并将命比做“周期函数”，社会有其运转的周期与函数，每个人也有自己的周期函数，在社会的某个时期，如果人与社会的函数相反，则会走“下坡路”。但是这种对“命”的解释和“运气”是有些混淆的。

我更偏向于之前《领导力》课上的自己的一个[[尤里卡时刻/flomo/2026-01-02/memo@2026-01-02\|想法]]——以目前的人工智能做类比，将命比做train出来的模型，每个人的模型都不一样，都会存在一些逻辑缺陷。而后天遇到的事情，都是对模型的输入，一些输入会触碰到缺陷而导致错误的输出（坏运气），有些时候能遇到好的输入使得模型修补缺陷而完善起来（比如遇到一位贵人，他或许就能帮你逆天改命），有些时候则碰到一些事情使模型增加错误的逻辑。因此，命只是一个起点，后天的环境以及运气都会对模型作出修改，但是假设命非常不好，那就是一个劣质模型，后天遇到负面影响的概率会更大。（Maybe 100年后的今天，换成了一堆机器人在讨论“什么是命”

所谓的一些人格（因为“命”与“运”可以转换，因此人格也是不断变化的）、算命，乃至心理、社会等人文科学，其实都是对这个模型机制的探索和解释。。

## 家庭的影响

+ **理想差距**：农民的孩子理想是走出农村，富人的孩子理想是财富自由；
+ **抗风险能力**：普通家庭出于失败风险会放弃创业，而富人家庭允许多次创业失败；
+ **性格影响**：穷人家庭的孩子普遍自卑、内向，在一些机会面前不愿主动展示自己；
+ 其他：资源、财富继承、文化素养等；

## 社会环境

社会环境是一个基本条件，生活在计划经济和市场经济、不同国家、不同社会形态都是不一样的。例如户籍制度导致的三农问题。

苏联模式的工业化是建立在对农民的剥削之上的。

+ 工业化需要进口设备，要卖农产品；
+ 工业化征调了许多农民，农民还要负担城镇的口粮，负担很重；

我国建国初期推行的“价格剪刀差”（提高工业品的价格，降低农产品的价格），导致农民收入购买力降低，大量农民涌入城镇，造成了城镇资源的短缺。于是，政府出台户籍制度，强制将人分为两类：城镇居民、农村人口，限制人员自由流动，至此之后的很多政策都是基于户籍制定的。

改革开放后，城镇劳动力不足以支持城市化发展，于是政府放松了户籍制度，让部分农民进入城镇，但是一些城镇人能够享受的待遇并没有给到这些农民工。

户籍制度目前很难改，因为牵一发而动全身。以养老金为例：城镇居民养老金有1000多/月，而农村养老金一个月就只有100多。如果要改善农村的养老金，势必会触及城镇人口利益（降低城镇居民的养老金），而政策制定者大多是城镇居民。[[memo@2026-03-07\|memo@2026-03-07]]

## 认知与运气

老师一个同学在07年跳槽到了银行，08年刚好爆发次贷危机，国家“四万亿”计划流入房地产，银行在这个政策中赚得朋满钵满，而在07年他是无法预测到这个机遇的，这就是运气。

A对行业1和行业2的未来发展趋势有清晰的判断，而做了正确选择，这认知内的选择并非运气；而B无法判断行业1和行业2的未来，选择了其中的夕阳行业而变穷了，这是运气不好。所以同一个选择对于认知不同的人是否是运气是不一样的。

我觉得在找工作这件事情上，运气确实非常重要。最近一位猎头打我电话，幸好当时我接了（一般推销、招聘的电话我都是直接挂的），才了解到做农业机器人的“觉物科技”和找猎头的意义，当然目前我仍然无法清楚它会给我带来什么。

## 自然禀赋

## 勤奋与选择

只有勤奋是与个人相关的，但在这其中，个人能决定的部分实际上也很少。

### 反抗

反抗是一种自我否定，但自我否定需要巨大的勇气，最佳的方式是别人经常肯定自己，然后自己经常否定自己。


### 选择

> [!NOTE] 
> 1. Life is simple. You make a CHOICE, and you never look back.——《速度与激情》台词
> 2. 未经审视的人生不值得过。——苏格拉底

尼采认为人生是一个圆，永恒轮回，做了一个小恶/小善，会成为无穷的恶/善，这样做一个决定就需要承受巨大的责任。

如果人生是单向的，此刻作出的决定会随着时间而淡化。假如之前做了一个决定，现在得到了不好的结果，但是并不知道当初选择另一个结果会不会更差。

过去的经历一定程度上决定了我们会做出什么样的选择，但是也会存在一定的自由意志去打破这个限制。有时候我们根据自己所理解的意义进行选择，有时候我们做出了选择，但不理解这一选择的意义，我们努力去理解这一选择的意义。

个人的选择就是自由意志。什么是平等呢——出于自由意志产生的行为应该由个人负责，而非自由意志导致的结果（各种不平等）不应负责。


# 消除非自由意志因素

运气是不可消除的。

## 如何消除家庭的影响

+ 极端方式：废除家庭；
+ 温和的方式：限制私立学校、私人教育等等。

## 如何限制自然禀赋

在一个与世隔绝的小岛上，人A眼睛完好，人B是瞎子，有两种选择：
+ 将A的一只眼睛移植到B上；——一小部分人会支持。
+ 将A的眼睛刺瞎；——没有人赞同，因为它导致瞎子的境遇变得更糟糕。


# 再分配

可以发现通过消除、限制非自由意志因素几乎不可能。那么，再分配就是调节社会不平等的必要措施。

## 自由主义对再分配的观点

[[尤里卡时刻/flomo/2025-03-30/memo@2025-03-30\|memo@2025-03-30]]

诺齐克在《无政府、国家和乌托邦》中提出“持有正义”的三个原则：
+ 获取的正义原则：如果一个人通过劳动获得了无主之物，并且给他人留下了足够多、同样好的东西，其获取就是正义的。
+ 转让的正义原则：任何形式的财产转移必须是自愿的。
+ 不正义的矫正原则：违反前两条的财物需归还或进行补偿。

只要一个人的财产符合这三个原则，政府就无权对其进行征税。
