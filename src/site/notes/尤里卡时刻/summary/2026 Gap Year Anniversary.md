2025.06.06，是我在DJI的Last Day，也可以说是我的“独立日”；而不知不觉中，我已经Gap一年了，在这个特殊的日子，应当好好反思和纪念一下这过去的一年。


**1). 如果用一个隐喻来形容你这整整一年的Gap Year，它会是什么？为什么？**

一朵随风飘荡的蒲公英种子。离职后变得自由，有了更多的时间去接触各种各样的[[尤里卡时刻/summary/2025 Summary\|人和事]]，但是又没有固定的方向：有时候是命运牵引着自己往前走[[尤里卡时刻/summary/2025 Summary#^a0a8f0\|2025 Summary#^a0a8f0]]，有时候自己会主动选择调转方向[[尤里卡时刻/summary/2026 Plan#^969e15\|2026 Plan#^969e15]]。

想要成为什么样的人，做什么样的事，对“理想土壤”的渴望和思考一直贯穿整个Gap Year。


**2). 当初为什么选择Gap Year？是否有具体的规划？**

当初选择Gap，更多的是职业倦怠下自然的选择，人生意义缺失的危机感迫使主体意识觉醒，希望通过Gap来探索新的可能性。

在这种觉醒初期迷茫的情况下，要制定具体的行动计划并坚持执行个人觉得是不现实的，但至少有一些具体的事情想立马去做，比如体验校园、学乐器等等。一开始想着只Gap半年就找份工作，但结果不知不觉到目前为止已经一年了。

**3). 这次Gap Year经历了哪些“关键转折”或“意外事件”，使得自己有了哪些重要的观念改变?**
{ #da6335}


最大的改变，在于我的人生观和职业观。

从小到大，我一直沿着社会规训的标准路径前行——家庭、教育、职场，三者共同铺设了一条没有服务区的高速公路。大家都在互相竞争、互相比较，不进则退。在这条流水线上，进大厂、拿高绩效、追逐丰厚的薪资和财富自由，成了衡量成功与优越感的简单指标。

促使我脱离这条轨道的关键契机，是年初一波三折的求职经历。

起初，我只想进一家975节奏的小厂，但意识到薪资要打七八折之后，心里不甘，又陆续投了几家强度更高的具身智能公司。然而真正到了抉择Offer的时刻，我恍然发现自己对WLB、对工作意义的渴望远比想象中更深，于是，逐渐放弃了对高薪资的执念。

接下来的两个事件，进一步拓宽了我的职业想象。

第一件事发生在策划同学录时——我认真做了一下MBTI测试，结果是INFJ。恰好那段时间我在面试非夕，第一次了解到“开发者关系管理”这类覆盖技术、产品、市场、社区多维度的岗位。我开始从人格特质的角度去思考：什么样的工作是我擅长且能带给我成就感和价值感的？

第二件事来自社会创新创业课。我发现在面对公益事业，去解决社会问题、传播爱的过程中，自己是充满生命力和激情的，这种感受在科技企业中似乎未曾有过。

总之，目前自己在择业上有了新的选择：能直接帮助到他人或者致力于解决社会问题，有机会写作甚至分享自己的思考，能够看到用户的需求并推动产品去解决他们的痛点。


**4).这次Gap Year，经历了哪些至暗时刻，如何走出来的?

这一年大概有三段至暗时期。

第一段是2025年秋季，与XBotPark接触后认识到自己能力的不足以及创业热情消退带来的迷茫[[尤里卡时刻/summary/2025 Summary#^a0a8f0\|2025 Summary#^a0a8f0]]，但因为当时在学习长笛、听喜欢的课，帮班级组织活动，具体的生活使自己得到了精神上暂时的慰藉。

之后是26年初，我开始求职，同时赶上OpenClaw的流行。对于半年没碰过代码与技术的自己来说，颇有与时代脱节之感——短短半年间，AI 编程已全面融入各大企业的软件开发流程，各类新概念、新产品更是层出不穷。当时的自己因此深陷焦虑，不仅对 AI 冲击下软件行业的职业前景感到极其悲观，也完全没有兴趣去卷 Agent 开发岗位。这种焦虑持续了一段时间，后来在补充AI、机器人相关知识的过程中逐渐平复。经过几轮面试的历练，我也逐步重拾了自信。

第三次，春招接近尾声。在拒绝了它石和傅利叶的Offer后，我原本很有信心能拿下非夕和穹彻，结果两家都翻车了。经历了十几次面试，我已感到深深的疲乏。与此同时，父母每周照例打来电话，问工作找得怎么样了、对象有没有着落，这让我既无奈又厌烦。而另一边，学院的讲师采访剪辑、同学录制作等事情还缠在身上，没能按预期脱身。那段时间没了做事的动力，连着两三天在家里摆烂，至于恢复的过程就是[[尤里卡时刻/summary/2026 Gap Year Anniversary#^da6335\|第三问]]的内容了。

**6). 这次Gap Year，哪些能力获得了提升，哪些能力有所下降？**

提升的方面：
+ 笔记系统：坚持每日、每周总结，建立了flomo+Obsidian的笔记组合；
+ 音乐素养：熟练吹奏长笛，学习了中西乐理，对上低音号、小号也有尝试；
+ 早睡早起的习惯：清明节后，基本7点多起床，23点睡觉，精神状态好了很多；
+ 运动：定期跑步、游泳、打羽毛球，自己摸索学会了自由泳；
+ 工程管理能力：完成了质量、管理导论、领导力、风险管理、创新创业的课程学习；
+ 机器人专业技术：学习了ROS2、电机等机器人技术知识；
+ DIY能力：开始尝试DIY一些项目，并接触了3D打印；
+ 演讲能力：多次课堂Pre；
+ 组织能力：担任班长，组织多项班级活动；
+ 宣传制作：视频剪辑、海报/邀请函制作、论坛直播系统；
+ 自我认知与内核建设：个人有缺点、MBTI、人生与职业观、正念练习；
+ 社交能力：对亲密关系的反思，变得稍微外向了些，结识了更多的人；
+ 开车技术：在西北两次自驾游；
+ 创业能力：学习一些必要的创业理念，参加或观看了一些创业比赛，积累了一些创业想法；
+ 投资能力：开通了美股账号，学习了怎么看财报，利用闲钱进行股市投资；

下降的方面：
+ 编程技术：写代码频率少了，前沿的AI技术没有跟上，要进大厂的话想对困难很多，没有连续性，企业的培养成本过高。
+ 个人资产：无收入，学费支出占大头；


**7). 这次Gap Year，有哪些遗憾，重来一次会如何做？**

主要有两点遗憾：
+ 上半学期精力比较分散，浪费了一些时间，没有尽早聚焦个人职业的规划，如果重来一次应该会在8、9月份就开始间歇性地投递一些简历进行面试练习，寻找合适的岗位；
+ 想得太多行动太少。待在校园里太久，没多去社会实践，导致回头看这一年觉得太平平无奇了！

支教结束后，应该会在9、10月份再尝试找一下工作，祝自己好运吧！
