# 方向1：AI时代的教育问题

2026.06.17

## 初心

我想要解决的社会问题：
+ AI、数字化时代，城市孩子面临更严峻的心理问题，可能找不到人生的意义与方向；
+ 在这样的时代如何为乡村孩子们缩小教育差距；
+ 改善快节奏时代的青少年、成人的亲子关系和代际隔阂；


## 行动

为了解决这个问题，可能需要做哪些行动。

一线体感：
+ 宏观视角关注AI与教育的研究与实践；
+ 参与暑期AI夏令营、青少年心理机构、家庭辅导公益机构的志愿者，去提升对问题的认知；
+ 参与乡村教育公益组织的驻校帮扶、短期支教、长期教研项目，加深对乡村孩子处境的理解；
+ 在一线实践中定期访谈，建立对青少年、师生、父母的追踪样本；

能力提升：
+ 深入学习和研究AI的前沿技术；
+ 个人DIY项目向AI技术、STEM教育硬件靠近；
+ 提升个人的演讲、授课能力；

理论沉淀：
+ 寻找MEM和AI教育重合的课题；
+ 学习儿童、教育、家庭、认知心理学知识；

落地扩圈：
+ 加入AI孵化器社会型企业，做课程研发，观察AI对孩子的影响，学习运作模式；
+ 寻找同频的人，参与公开分享机会，建立个人影响力；

## 评估

不利因素：
+ 没有教育行业的工作经验，没有心理学/教育学背景，从零开始跨入一个专业领域；
+ 教育行业的反馈周期极长；
+ 未曾创业过，相关的能力欠缺；

有利因素：
+ 有真实的工程一线经验；
+ 交大MEM就读，拥有平台资源、导师网络、同学圈子；


## 里程碑

第1年（验证期），需要回答几个问题：

- 我是否真的喜欢和孩子们在一起？
- AI教育这个领域，是否有真实的需求缺口，我认为的社会问题是否真的存在？
- 我在AI孵化器这样的组织中，能找到让我持续投入的兴奋点吗？
- 对我认为的社会问题，是否有自己坚信的解决方案？

- [ ] 2026.09 在暑期实践后，再次评估方向与行动；
- [ ] 2027.06 评估是否在原组织继续实践还是去往新的平台；

第3-5年（站住脚），要让自己成为这个领域不可绕过的人：
+ 在AI教育赛道有了2-3年的一线实践，对这个问题有自己独到的见解；
+ 做出1-2个有价值的成果（课程产品、项目报告、学术论文、公益案例等）；
+ 建立起初步的行业口碑和人际关系网；
