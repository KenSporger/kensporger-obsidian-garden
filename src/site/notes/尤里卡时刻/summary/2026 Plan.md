# 年度计划（02.12）

**四大主题**：找工作、毕业论文、ROS小车项目、乐器练习；

+ 【想成为的人】
	+ 兼具技术与管理能力的：拥有系统的技术与管理知识体系，并能通过实际项目成果量化证明。
	+ 有秩序和方向感的：持续深化自我认知，明确人生意义，坚定走在实现个人价值的道路上。
	+ 勇敢自信的：在音乐上主动与同好交流、登台演出；在学业上勇于与导师和优秀同侪深入对话。
	+ 博爱的：提升爱的能力，以理解、尊重和关心对待他人，超越个人欲望。
+ 【知识管理】
	+ 坚持使用Obsidian+flomo系统，进一步优化两者间的关联度，不再折腾新的工具；
	+ 领域聚焦，重点输出整理工程管理、机器人两方面的笔记；
	+ 优化MEM课程笔记方式，兼顾系统性与高效性；
	+ 实现工作笔记的安全云同步，避免只存在公司系统里，重点记录有价值的东西；
	+ 革新阅读笔记方式，探索原子化阅读的可行性，删减书籍数量，多精读；
+ 【音乐】
	+ 工作后保持一周三次长笛练习的频率，攻克手指速度瓶颈，做到吹奏时上身放松不紧张；
	+ 进行一次学校音乐会的演出；
	+ 能和别人完整合奏一支曲子；
	+ 铜管乐器学习入门，能吹奏三四首小曲子；
+ 【工作&个人项目】
	+ 找机器人方向的工作，能从中收获成就感，强度适中（975左右）；
	+ 承担一定的管理工作，能与毕业论文课题结合；
	+ 完成RoboRTS在ROS小车项目上的迁移；
+ 【学业】
	+ 两个学期末、暑假各组织一次班级聚会活动，全年共三次；
	+ 完成行业论坛热场视频制作、B站回放上传（此外的学校活动不再投入精力）；
	+ 修完所有课程学分，完成50篇论文的阅读；
+ 【家人&人际关系】
	+ 解决父母的退休问题；
	+ 谨慎交友，向上社交，与本文所列的同学保持互动交流；
	+ 不再打扰她，接受新的可能，学会理解、尊重与关心；
	+ 加强与导师的交流，每季度至少一次进度汇报；
+ 【投资理财】
	+ 价值投资而非投机，5%的资产用于港美股投资，其余基金、储蓄；
	+ 了解个人养老金；



# 03.23-06.23

在投递岗位和面试时候发现，AI工具已经深入渗透到了研发中，gap半年导致这一块成了短板，也不得不从长远角度考量到底应该选择什么样的公司以及岗位方向，才不至于被AI替代。

另一个现实就是，很少有强度适中且能接得住自己薪资的机器人公司，但转去做纯软的AI应用开发又不是自己的兴趣所在。

因此接下来的一个月，重点在于思考清楚这个问题，并且找到可持续的工作。

- [ ] 在ROS项目上应用Cursor、Claude Code AI编码，学习AI相关概念；
- [ ] 在房子到期前找到新的家；
- [ ] 因为准备面试，读论文和练笛子都有些懈怠了，还是要保证一定的占比；
