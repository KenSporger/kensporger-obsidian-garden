# 宏观市场

## 政策法规
{ #62c017}


2025年4月，教育部等九部门联合发布《关于加快推进教育数字化的意见》（教办〔2025〕3号），明确提出“以教育数字化为重要突破口，开辟教育发展新赛道”。

全息技术在教育领域的应用已获政策明确支持。教育部在“十五五”时期重点工作部署中提出，要“建立全息、全域、全员、全时的沉浸式思政育人模式”

2025世界数字教育大会进一步明确，要“融合全息投影、数字孪生等技术，构建沉浸式虚实融合教学场景”。

**政策研判**：教育数字化与全息教学受到国家层面强力推动，为AI全息学伴提供了坚实的政策背书。但产品设计需严格遵循未成年人保护要求，在“陪伴”与“辅导”之间找到合规的平衡点。


## 人口结构
{ #addd40}


**K12在校生规模庞大，构成巨大市场基本盘**

中国K12阶段（小学、初中、高中）在校生总数约2.2亿人，其中小学阶段在校生约1.1亿人。这是AI全息学伴最核心的潜在用户池。

**教育信息化用户基础持续扩大**

国家智慧教育平台累计注册用户已突破**1.64亿**，表明数字化学习方式已获得大规模普及。随着教育信息化的快速推进，3D教学资源的市场需求持续增长。

**人口红利**：2.2亿K12在校生，小学阶段1.1亿学生是AI全息学伴最直接的受众。


## 经济周期
{ #e61264}


**教育硬件市场：逆势高增长**

与消费电子大盘的疲软（2026年多数消费电子产品仅增长1%）形成鲜明对比，教育智能硬件市场呈现出强劲的增长势头：

![da7be702780aa632a86780b9a1d496a2_MD5.png](/img/user/DIY%E9%A1%B9%E7%9B%AE/%E9%AD%94%E6%96%B9-%E7%AB%8B%E4%BD%93%E8%A7%86%E8%A7%89%20%E6%95%B0%E5%AD%97%E6%95%99%E8%82%B2/assets/02.%20%E6%95%99%E8%82%B2%E7%A1%AC%E4%BB%B6%E5%B8%82%E5%9C%BA%E7%A0%94%E7%A9%B6/da7be702780aa632a86780b9a1d496a2_MD5.png)

- 2017年市场规模仅**376亿元**，2025年已达**1125亿元**，八年翻近三倍
- 2025年学习平板全渠道销量达**632.1万台**，销售额**199.1亿元**。

全球视角下，2025年全球与中国教育硬件市场规模分别为**4266.47亿元**与**1369.54亿元**（人民币），预计全球市场在2032年将达到5958.84亿元，年复合增长率为4.89%[](https://dxpress.gelonghui.com/p/3449417)。

从更广义的“智慧教育”来看，2025年中国智慧教育与学习市场规模达**9453.98亿元**（人民币）；教育信息化市场规模约**5333亿元**；教育科技与智慧课堂市场规模达**2779.03亿元**。


**AI端侧创新成为破局关键**

教育硬件正从“工具型硬件”全面转向“个性化AI家教”。AI大模型与智能硬件的深度绑定正在持续为行业赋能。

**经济研判**：教育硬件是当前消费电子领域少数逆势高增长的赛道。家长对智能化助学工具的消费意愿持续增强，AI全息学伴作为教育硬件的新品类，有巨大的增长空间。定价可参考主流价格带——2000-2999元已成为学习平板的主流价格带，线上销量占比达**45.9%**。

## 社会心理

**家长的教育焦虑持续升温**

“双减”政策后，家长对“孩子未来竞争力”的焦虑并未消失，而是从“找培训班”转向了“买AI学习设备”，76.3%的家长将“AI教学深度”列为选购教育硬件的首要因素。

**“陪伴真空”成为普遍痛点**

双职工家庭普遍面临“没时间陪孩子学习”的困境。家长需要的不仅是一个“教知识的工具”，更是一个能分担陪伴压力、激发学习兴趣的“伙伴”。

**社会心理研判**：家长对“AI辅助教育”的接受度正在快速攀升。AI全息学伴若能同时回应“提分焦虑”和“陪伴缺失”两大心理痛点，将精准切中家长的核心诉求。


## 文化现象
{ #a629ee}


**AI+教育成为全民共识**

2025年被定义为“智慧教育元年”。

**数字化学习方式被广泛接受**

当前小学生本就是“数字原住民”，对AI互动、数字化学习的接受度远高于前几代人。国家智慧教育平台累计注册用户已突破**1.64亿**，表明数字化学习方式已获得大规模普及。

**文化研判**：AI+教育的文化接受度已基本成熟，用户教育成本较低。


## 科技发展

[[DIY项目/魔方-立体视觉 数字教育/01. AI全息数伴市场研究#^ff14b4\|01. AI全息数伴市场研究#^ff14b4]]

全息显示与AIGC的交叉融合正处于**技术爆发前夜**，全息技术在教育领域的应用已有多个真实案例：

- **内蒙古乌兰浩特市白鹭学校**：建设史地实验室，配备3D全息模型与3D影效，学生可“走进”亚洲立体地形图学习地理[](https://xam.nmgnews.com.cn/system/2025/10/21/030246469.shtml)
- **重庆交通职业学院**：发布“全息超时空互动教学平台”，以5G为脉络、全息成像为媒介，支持多地师生“共聚”全息课堂
- **山东大学**：建成“一校三地5G全息互动教学系统”，获山东省视听应用推广工程典型案例一等奖
- **广东佛山灯湖三小**：建设“未来教室”，使用全息投影、助教小精灵辅导学习
- **四川广汉援建金阳中学**：数字化地理教室配备裸眼3D全息投影仪，将地貌、气候、生态等信息立体展示

全息教室被定位为 **“未来学校的核心配置”** ，其核心价值在于：**沉浸式教学体验**（教学内容立体化呈现）、**跨区域资源共享**（基于5G和云计算）、**个性化学习路径推荐**。


# 微观市场

## 产业链全景

**上游：硬件设备与核心技术**

- **传感器**：摄像头模组（舜宇光学、丘钛科技、欧菲光）、麦克风阵列（歌尔微电子、瑞声科技）、环境光传感器（ams-OSRAM、Broadcom）、惯性测量单元（Bosch、意法半导体）
- **显示设备**：透明显示屏（洲明科技、美矽微视觉、利亚德）、柔性曲面屏（三星、京东方、TCL华星）
- **芯片**：主控芯片（瑞芯微、高通）、AI芯片（英伟达、华为昇腾）、电源管理芯片（德州仪器、士兰微）、存储芯片（三星）、音频芯片（炬芯科技、艾为电子）、通信芯片（高通、乐鑫科技）
    

**上游：内容服务与技术授权**
- **大模型**：千问、豆包、DeepSeek、MiniMax等
- **3D建模与设计**：世优科技、半图科技、沃山科技等
- **教育内容IP**：与教材出版社、教育机构的内容合作
- **AIGC内容生成**：文生3D、图生3D等能力授权
    

**中游：整机设计、SMT贴片、组装、系统集成**

- 产品ID/MD设计、主板方案设计、系统软件开发、整机组装、软硬件联调
    

**中游：云服务与平台技术**

- **云服务**：算力和基础设施（阿里云、华为云、腾讯云）、RTC实时音视频服务（声网）
- **教育SaaS**：学习数据分析、个性化推荐系统
    

**下游：渠道销售、品牌营销**

- **线上渠道**：电商平台（京东、天猫、抖音）、内容平台（小红书、B站）
- **线下渠道**：书店、数码卖场、教育展会
- **众筹首发**：Kickstarter等平台验证市场
    

**下游：用户运营与社区生态**

- **家长社区**：学习报告分享、育儿经验交流
- **儿童社区**：学习成果展示、宠物养成互动（在严格监管框架下）
- **内容创作者生态**：3D模型、学习场景的UGC创作与分享

### 儿童陪伴机器人

2025年国内AI玩具市场规模达**290亿元**，陪伴型机器人占比超**35%**。全球儿童陪伴机器人市场规模约**11.27亿元**。

代表产品包括：**阿尔法蛋系列**（科大讯飞旗下）、**FoloToy**（自研儿童语义理解模型，无屏幕设计）、**汤姆猫AI童伴机器人**（国民级IP）、**联想AI童伴机**（599元）、**奇多多AI学伴机**（无屏幕，延迟<250ms）。

**核心短板**：教育内容深度不足，多停留在“讲故事、陪聊天”层面，缺乏系统的学习辅导能力。
