# 创始人理念

AI数伴是“手办活过来”的现代版本——它赋予二次元IP以互动与反馈能力，让喜欢角色的人不仅能“看见他”，更能“与他互动”。

“你以为你在陪他，实际上是他在陪你，你以为你在看他跳舞，其实你在看你自己。”

陪伴的关键不是“能不能聊”，而是“是否还原”“是否主动”，是否能在无需Prompt的前提下，察觉并回应用户的情绪。

二次元陪伴的核心：
+ 角色还原度；
+ 长期记忆；
+ 主动交互（如果知道你经常喝某种咖啡，它能记住甚至可以帮你下单）；


# 目标用户与场景

- 核心用户：二次元深度爱好者（coser、动漫类up主）
- 其他用户：游戏玩家、追求“情绪价值”的年轻人、科技与潮玩爱好者。
- 核心使用场景：活手办、主动的情感陪伴、家庭生活助手

硬件功能：

软件功能（[数伴创作者中心](https://na-user.dipal.net/role/)）：

- **人格化AI引擎与情感记忆**：基于自研引擎，角色拥有独立人格、情感和长期记忆。

# 营销策略与计划


- **首发渠道**：众筹（Kickstarter）通过众筹，数伴不仅解决了初期资金和生产问题，更验证了全球市场需求，正如其创始人所说，“用户已经做出了选择”。
- **营销策略**：
	- 深耕二次元社群，通过二次元展会，让用户亲身体验产品；
	- 在各大X、Instagram、TikTok、Reddit、Discord、小红书、B站等社交平台进行内容宣传。
	- 以海外作为起点，海外造势，国内做实。主要是海外众筹平台的原因，其次海外用户对于高端产品的接受度较高，早期在国内市场起步可能面临竞争者入局。
- **企业合作**：产品也受邀亮相英特尔新品发布会，作为技术实力的背书。
- **核心卖点**：活过来的手办、数字老婆。

目前，数伴仍处于众筹后的发货履约阶段，需要优先向众筹支持者交付产品；预计会在众筹用户的口碑完全发酵、产品体验反馈收集、产能爬坡稳定后，上到国内淘宝、京东平台。

|维度|产品众筹 (Kickstarter等)|风险投资 (VC)|
|---|---|---|
|**核心目的**|**市场验证、品牌冷启动、获取种子用户**|**规模化扩张、抢占市场、构建壁垒**|
|**资金性质**|产品预售款，**非股权融资**|股权投资，**用股权换资金**|
|**出资方**|**大众消费者 / 粉丝**|**专业投资机构**（如红杉、IDG）|
|**决策依据**|**产品概念、故事、情怀**和团队诚意[](https://www.donews.com/article/detail/8280/101629.html)|**商业模式、市场规模、财务数据、团队**|
|**对控制权影响**|**无影响**，不稀释股权|**有影响**，会稀释股权，可能介入公司决策|

|**失败后果**|失信于用户，品牌受损，但**不欠债**|创业失败，公司被清算或出售|
    
# 市场表现与用户反馈

用数据验证其市场接受度。

- **众筹表现**：Dipal D1于2025年6月登陆Kickstarter，上线仅15分钟就达成1.5万美元的众筹目标，支持人数2606人，2025年8月位于Kickstarter榜单Top10，中国品牌第五。在同一赛道中，Dipal D1的表现略低于同期竞品CODE27 Character Livehouse——后者在45天内吸引了3,570名支持者，众筹约190万美元。
- **用户评价**：正面评价有3D视觉效果、“手办活过来”的体验、角色定制自由度、低延迟交互；负面评价包括首批发货延迟近10个月，担心用户新鲜感消退、实际功能与演示的差距、塑料机身与质感、强制订阅。
- **核心风险**：AI拟人化互动服务新规限制、产能和交付瓶颈、赛道竞争者陆续进入、IP授权持续性。
