# 宏观市场

## 政策法规

**利好政策：产业扶持力度持续加码**

全息显示技术已被纳入国家及地方重点产业规划。2025年7月，上海市发布的[《下一代显示产业高质量发展行动方案（2026-2030年）》](https://www.shanghai.gov.cn/qtsj/20250724/99b59d9035564029bb9851dbfa69e594.html)将**全息显示技术列为三大未来显示前沿方向之一**，指出要重点突破**Micro LED、硅基OLED、柔性显示**等下一代显示关键技术，明确提出“支持无介质3D全息显示技术及产品研发与产业化，鼓励全息显示与元宇宙、数字人等结合”。

在数字人领域，国务院2025年发布[《关于深入实施“人工智能+”行动的意见》](https://www.mee.gov.cn/zcwj/gwywj/202508/t20250827_1126207.shtml)，提出在办公、社交、消费、娱乐等领域**加快人工智能与元宇宙、数字人技术结合**，探索创新应用场景。

**监管政策：针对AI情感陪伴类产品的监管迅速收紧**

2026年4月10日，国家网信办等五部门联合发布[《人工智能拟人化互动服务管理暂行办法》](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm), 这是全球首个专门针对AI情感陪伴、虚拟伴侣等场景的国家级监管规则，将于2026年7月15日正式施行，核心条款包括：

- **严禁向未成年人提供虚拟亲属、虚拟伴侣等虚拟亲密关系服务；**
- **所有服务必须完成算法备案和安全评估；**
- **明确拟人化服务的伦理边界和安全管理义务；**

《办法》还要求服务提供者具备**用户隐私权保护、过度依赖风险预警、情感边界引导、心理健康保护**等安全能力，**不得将替代社会交往、控制用户心理、诱导沉迷依赖等作为服务目标**。

**政策研判**：产业扶持与合规监管并行——一方面全息显示和数字人被列为国家重点发展方向，另一方面AI情感陪伴面临严格监管。AI全息数伴需在产品定位上**避开“虚拟亲密关系”红线**。

## 人口结构

**老龄化加剧，“银发孤独”催生刚需**

中国正在快速进入深度老龄化社会。截至2025年，60岁以上人口预计突破3亿，其中独居、空巢老人占比持续攀升。这些长者在精神上面临巨大的孤独危机，传统家庭照料模式难以持续。

**单身与独居人口激增**

2025年中国单身人口已达2.97亿，占总人口的20.7%。独居成年人口超过7700万，25-29岁年龄段未婚率已突破51.3%。

**人口红利**：庞大的独居、空巢、单身人群构成了AI全息数伴的**天然目标用户群**——他们既有情感陪伴的强烈需求，又有为“情绪价值”付费的意愿和能力。


## 经济周期

**消费电子行业：股市AI概念火热，但民众消费购买热情不高**

申万消费电子行业投资指数全年上涨47.5%，但展望2026年，多数消费性产品出货预计仅温和增长1%左右。

**AI端侧创新成为破局关键**

在存储芯片持续涨价的成本压力下，厂商利润被挤压，端侧AI正成为破局的关键力量。

**AI情感陪伴市场高速增长**

2025年中国AI情感陪伴行业市场规模约为‌**38.66亿元**‌，预计2028年将突破‌**595亿元**。中国AI情感陪伴行业渗透率快速上涨，预计到2028年，行业渗透率将上涨至13.12%。

**经济研判**：宏观经济增速放缓背景下，消费电子大盘确实在经历“消费降级”——大宗硬件换新需求疲软。但“情绪价值消费”赛道正在逆势崛起。


## 环境变迁
{ #589cf9}


**绿色消费与低碳转型**

2026年，[《关于实施绿色消费推进行动的通知》](https://www.mofcom.gov.cn/zwgk/gztz/art/2026/art_fb094fc0f3124682ad9e6cab0382e188.html)正式印发，政策重心向绿色消费跃迁。

**供应链与地缘政治不确定性**

2025年电子产业链为规避美国潜在关税壁垒与地缘政治风险，普遍出现显著提前拉货现象。

**环境研判**：传统手办在原材料生产、废弃处理及劣质产品带来大量化学污染，而AI全息数伴作为低能耗、无物理耗材的数字产品，符合绿色消费趋势。但需关注供应链成本压力对硬件定价的影响。


## 社会心理

**普遍性孤独感成为社会常态**

城市化加速、家庭结构变迁、人口老龄化加剧、独居青年与空巢老人数量激增，共同催生了普遍存在的孤独感。“陪伴服务”不再是一种奢侈的情感消费，而是正在成为一种刚需型社会服务。

**情绪价值消费崛起**

近六成青年愿意为情绪价值买单，较2024年增长16.2%。年轻人正从“物质偏好”转向“情绪满足”，通过购买行为应对孤独感、压力和焦虑等情绪问题。

**社会心理研判**：社会性孤独已从个体情绪演变为结构性社会问题，AI全息数伴若能提供较好的的陪伴体验，将精准切中这一社会心理痛点。


## 文化现象

**虚拟偶像与数字人文化成熟**

虚拟偶像已从边缘亚文化走向主流。洛天依等虚拟偶像穿梭于电视台、视频网站的各种文艺晚会。AI驱动的数字员工已进入直播带货、品牌代言等商业场景。

**二次元文化走向主流经济**

- ‌**泛二次元用户规模**‌：2025年已达‌**5.26亿人**‌，横跨“80后”至“10后”，接近网民规模的一半 。
- ‌**产业总规模**‌：2024年泛二次元及周边市场规模达‌**5977亿元**‌；2025年周边市场规模预计突破‌**6521亿元**‌ 。
- 核心人群为Z世代（15-30岁），占比超60%，其中95后在二手交易（如闲鱼痛文化商品）中占比超70% 。

**挑战：数字人IP“短命”困境**

然而，众多曾红极一时的数字人悄然淡出，数字人IP普遍面临“短命”困境。

**文化研判**：虚拟数字人已获得广泛文化接受度，为AI全息数伴提供了良好的用户认知基础。但需解决IP生命周期管理问题，避免沦为昙花一现的“快消品”。

## 科技发展
{ #ff14b4}


**全息显示技术取得关键突破**

全息显示技术正从实验室走向产业化：

- 清华大学团队实现与人类视觉感知相一致的物理光学散焦效果，显著提升三维显示真实感
- 研究团队实现高速亚波长级波前调控，首次跨越实时动态三维全息显示的性能门槛
- 三星研发MH1全息3D屏，采用眼球追踪技术实现裸眼立体显示，预计首发搭载苹果产品
- 谷歌Beam设六摄像头阵列，AI视频模型可实时拼接创建毫米级精度的3D人物

**AIGC赋能3D内容生成**

AIGC已能生成具有空间深度的3D模型视频，腾讯混元系列支持秒级生成3D场景。AI与超表面设计的结合，为全息显示提供了全新路径。

[Meshy-2: AI 生成 3D 模型发展到哪了？](https://zhuanlan.zhihu.com/p/681621437)
[Taichi NeRF (下): 关于 3D AIGC 的务实探讨](https://zhuanlan.zhihu.com/p/613679756)

**技术研判**：全息显示与AIGC的交叉融合正处于技术爆发前夜。核心器件成本、实时计算能力仍是瓶颈，但突破速度远超预期。

## 总结

| 维度   | 核心判断             | 机会/风险        |
| ---- | ---------------- | ------------ |
| 政策   | 产业扶持+严格监管并行      | ⚠️ 需规避亲密关系红线 |
| 人口结构 | 3亿老人+3亿单身=巨大陪伴刚需 | ✅ 最强需求驱动     |
| 经济周期 | AI端侧创新破局，陪伴经济高增长 | ✅ 符合价值驱动方向   |
| 环境变迁 | 绿色消费+供应链成本压力     | ⚠️ 关注硬件成本    |
| 社会心理 | 普遍性孤独，情绪价值消费崛起   | ✅ 精准切中痛点     |
| 文化现象 | 虚拟数字人接受度高        | ✅ 用户教育成本低    |
| 科技发展 | 全息+AIGC技术突破加速    | ✅ 技术可行性提升    |
利：AI、全息政策扶持，老龄化、单身、孤独心理 、二次元文化
风险：真正的全息技术还在研究、AIGC能力有待提升、虚拟陪伴监管比较严格

策略：
+ 目前面向低端市场，提供低成本的伪全息硬件，重点研究结合AIGC的软件能力；在真全息技术爆发后，迅速更新硬件，打入高端市场。
+ 主要面向18-30岁人群，避免明面过度宣传伴侣等情感陪伴，儿童、老年，降低产生的伦理监管风险。

## 产业链全景

**上游：硬件设备与核心技术**

+ - **传感器**：摄像头模组（舜宇光学、丘钛科技、欧菲光）、麦克风阵列（歌尔微电子、瑞声科技）、红外传感器（迈来芯、睿创微纳）、环境光传感器（ams-OSRAM、Broadcom）、触摸/压力传感器（汇顶科技、歌尔股份）、惯性测量单元（Bosch、意法半导体）
- **显示设备**：透明显示屏（洲明科技、美矽微视觉、利亚德）、柔性曲面屏（三星、京东方、TCL华星）
- **芯片**：主控芯片（瑞芯微、高通）、AI芯片（NPU/GPU，英伟达、华为 昇腾）、电源管理芯片（德州仪器、士兰微）、存储芯片（三星）、音频芯片（炬芯科技、艾为电子）、通信芯片（蓝牙/WiFi，高通、乐鑫科技）

**上游：内容服务、技术授权**
- **大模型**：千问、豆包、DeepSeek、MiniMax等
- **数伴形象建模与设计**：世优科技、半图科技、沃山科技等
- **IP内容与生态**：米哈游《原神》《崩坏：星穹铁道》、鹰角《明日方舟》、腾讯《王者荣耀》、网易《蛋仔派对》《第五人格》、库洛游戏《鸣潮》、虚拟偶像/B站Up主（初音未来、洛天依、嘉然、阿萨Aza等）、日漫/国漫、形象IP（泡泡玛特）等



**中游：整机设计、SMT贴片、组装、系统集成。**

**中游：内容服务、技术授权**

+ **云服务**：算力和基础设施（阿里云、华为云、腾讯云）、RTC实时音视频服务（声网）、知识库中间件（FastGPT、MaxKB、ChatWiki）
+ **开放平台与API生态**：数伴的AI能力可以接入企业微信、微信公众号、飞书、钉钉等。


**下游：渠道销售、品牌营销、售后服务。**
- **线上渠道**：**电商平台**（京东、淘宝、咸鱼等）、内容分享平台（小红书、B站、A站等）、**众筹平台**（如Kickstarter）进行宣传和销售。
- **线下渠道**：二次元周边门店。

**下游：用户运营、社区与生态**
+ **UGC创作型社区**：用户可上传、创作和分享角色模型，形成内容生态，例如AIFriends。
- **模型分享社区**：如 Civitai（AI模型分享社区）、魔乐社区（AI模型托管与分享平台）。
