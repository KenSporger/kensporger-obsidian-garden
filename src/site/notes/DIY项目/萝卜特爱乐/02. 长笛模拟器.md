项目地址：[Flute Simulator](https://github.com/KenSporger/Flute-Simulator)

# 项目背景

主要是作为MIDI学习的一个练习，同时考虑后自动长笛演奏这个项目在进实体调试之前需要有一个模拟器去优化乐谱解析、指法组合、强弱变化等等，因此手搓（AI搓）了这样一个玩意儿。

# 功能规划

目前已经具备的功能：
+ MIDI文件解码
+ 长笛按键标定
+ 指法可视化
+ 长笛音色输出
计划未来加入的功能：
+ 实时乐谱渲染
+ PDF、PNG转谱
+ MP3演奏模仿再现

# 实现细节

## 指法可视化

这块主要参考了[Tomplay](https://play.tomplay.com/v2/index.php?id=1076&pid=6381&lang=en)的设计。首先从村松、珍珠、三响、雅马哈、宫泽官网上去找高清的长笛2D图，最终选定了[三响14K](https://sankyoflutes.com/models/gold-flutes/14k-gold/)这支型号（无他，唯图高清尔）。

然后，指法的展示实际上是对[每个按键](https://github.com/KenSporger/Flute-Simulator/blob/main/flute/keys.py)都预先做了圈选，记录关键特征点，演奏时实时绘制叠加。为了抠出特殊形状，用了[Sobel梯度+Live Wire](https://github.com/KenSporger/Flute-Simulator/tree/main/calibration)实现了PS磁性套索类似的功能，**不过效果感觉比Tomplay的要差一些**。

![DIY项目/萝卜特爱乐/assets/02. 长笛模拟器/9970250e548b690d0855c4b9cc7d0ed3_MD5.png](/img/user/DIY%E9%A1%B9%E7%9B%AE/%E8%90%9D%E5%8D%9C%E7%89%B9%E7%88%B1%E4%B9%90/assets/02.%20%E9%95%BF%E7%AC%9B%E6%A8%A1%E6%8B%9F%E5%99%A8/9970250e548b690d0855c4b9cc7d0ed3_MD5.png)

[指法定义](https://github.com/KenSporger/Flute-Simulator/blob/main/flute/fingerings.py)上，主要症结在于**Bb的指法**：对于人类演奏，像Eb调的谱子，一般直接左手大拇指按住Bb键，而C调这种，左手大拇指则按住B键，谱中临时变调的话大拇指进行移动切换。但这个逻辑实现起来有些复杂，而且机械装置也不太好做切换，故目前采用的是B键+F键的方式。

## 音色库

项目使用了`FluidSynth`开源库，将MIDI数据合成为音频信号。对应的演奏音色由`soundfont`文件指定，即音色库。几个比较好听的长笛免费音色库：
+ [polyphone](https://www.polyphone.io/en/soundfonts/flutes) 
+ [MuseScore_General](https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/)

一些非官方制作的soundfont通常没有按照标准格式排，正常长笛音色库是在`program=73`，但是大多个人制作放在`program=0`。


## 播放逻辑

整个可视化播放过程按如下逻辑运行：
1. 通过`ticks_to_seconds`将MIDI文件里的Message转为绝对时间；
2. 通过`active_notes_after_event`计算每个Message发生后被激活的音符列表（一般来说，独奏就只有一个音符）；
3. 将该音符列表加入到schedule中，当处理完所有Message之后，整个schedule看起来是这样的，每个音持续1.2s后立即接上下一个音；
```
[
(0.0, {}), # 初始化
(0.0, {59: 81}), # 演奏B3音
(1.2, {}), # 停止演奏
(1.2, {60: 76}), # 演奏C4音
(2.4, {}), # 停止演奏
(2.4, {61: 80}), # 演奏C#4音
...
]
```
4. 在 `run()` 主循环中，启用Time定时器，一秒刷新60帧，然后每一次检查对比schedule的绝对时间，决定是否演奏下一个音符；
```python
wall = (time.perf_counter() - self.t0_perf) * self.speed  # 实际播放秒数（支持倍速）
# 查表：找到当前时间对应的活跃音符
while self.idx + 1 < len(self.schedule) and self.schedule[self.idx + 1][0] <= wall:
    self.idx += 1
_, active = self.schedule[self.idx]
```
5. 对每一个演奏的音符，通过`fingerings_for_notes`获取按键指法，通过 Pillow+Pygame 渲染高亮效果；
6. 同时，将当前active的音符列表同步给fluidsynth引擎，包括音名+力度信息，实现发声
```python
self._audio.sync_notes(active if len(self.schedule) > 1 else {})
```

# 改进项

存在以下待优化项：
+ 演奏效果很大程度上取决于midi的编码器，影响了演奏的流动性、力度变化以及乐器技巧，目前使用的是Sibelius（感觉musiccore更强一些），无法正确处理装饰音；
+ 颤音的指法有问题，目前是全部松开再按下所有指法涉及的按键，但实际上应该是快速按下其中一个即可；
