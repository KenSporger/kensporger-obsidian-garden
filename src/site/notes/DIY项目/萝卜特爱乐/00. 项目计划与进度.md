# 方案构思

了解现有的自动演奏装置方案，识别技术难点，构思创新点。

- [x] 阅读[[学术研究/论文笔记/论文11-Semi-Automatic Flute Robot and Its Acoustic Sensing\|论文11-Semi-Automatic Flute Robot and Its Acoustic Sensing]]
- [x] 了解[[机器人世界/硬件学习/02. 舵机工作原理\|舵机]]、电磁铁、[[机器人世界/硬件学习/03. 音圈电机\|音圈电机]]等执行器原理
- [x] 了解[[01. Python MIDI解\|MIDI输入原理]]
- [ ] 研究笛头吹气方案

 技术难点：
 + 克服执行器的噪音问题；
 + 吹气的角度、力度、气量控制，以及与执行器的精准配合；
 + 音乐演奏的艺术性，包括强弱变化、吐音、颤音技巧的机械实现；
主要方案：
+ 改造硬盘音圈电机控制按键，具备静音、响应快的优点，主要风险为发热、力矩大小；
+ 软件上使用Python对MIDI解码，映射成机械的指法控制，艺术性通过改良MusicXML->MIDI的编码算法来优化；

# 可行性验证

针对音圈电机发热、力矩大小进行提前测试验证。
- [x] 机械硬盘拆解、焊接通电初步测试力矩、发热情况
    连接3V电压，电流0.2A（阻值13.7欧），有一定力矩，持续1分钟发热明显但不至于烫手。因为焊接线会和机械硬盘底座摩擦导致无法全角度摆动，因此需要制作基座进一步测试
+ [ ] 硬盘VCM基座结构设计、3D打印，推力、颤音、升温、噪音测试

验证结论：
+ 机械硬盘使用希捷Desktop SSHD 1T型号（ST 1000DX001），该型号音圈电机线圈连接暴露较多，固定孔采用可拆卸螺丝，方便焊接和基座结构设计。
