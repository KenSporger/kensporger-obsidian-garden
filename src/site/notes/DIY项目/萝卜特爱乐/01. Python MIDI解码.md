# 基本概念

## MIDI格式

MIDI 格式是一串字节流，由一个个消息组成，而一个消息通常占1～3个字节，由以下部分构成：
+ Status Bytes：占一个字节，最高位为1，数值范围0x80-0xFF，定义了消息的类型（作用），如音符开（0x9n，n为通道号，范围0x0-0xF）、音符关（0x9n）；
+ Data Bytes：长度取决于消息类型，最高位为0，数值范围0x00-0x7F；

例如开启中央C（C4）音符，消息为`92 3C 64`，各部分含义如下：

```
92 -- 9 == message type note on
      2 == channel 2

3C -- note 60 (middle C)

64 -- velocity (how hard the note is hit)
```

在MIDI中，消息类型被分为四种：
+ Channel Messages：用于对单独某一个通道的音符进行演奏方式和基本表现力的控制，MIDI支持最大16个通道，每个通道可以是一个乐器；
+ System Real Time Messages：用于同步多个设备，以及控制开始、停止、继续；
+ System Common Messages：主要用于选择歌曲、设置歌曲位置指针等；
+ System Exclusive Messages：用于特定品牌设备的升级、配置等等；

## note和音名转换

- 八度级别：`octave = note // 12 - 1`
- 音高：`pitch_class = note % 12`（0=C, 1=C#, …, 11=B）

例如note=60，则octave=4, pictch=C，即音名C4，转换函数如下：

```python
def midi_note_to_name(n, prefer_flats=False):
    sharps = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B']
    flats  = ['C', 'Db', 'D', 'Eb', 'E', 'F', 'Gb', 'G', 'Ab', 'A', 'Bb', 'B']
    names = flats if prefer_flats else sharps
    octave = n // 12 - 1
    return f"{names[n % 12]}{octave}"
```

选取《卡门》间奏曲的前两小节，通过Sibelius编码导出为midi文件。再通过Python mido解析，解析代码如下：

```python
from mido import MidiFile

mid = MidiFile('carmen suite.mid')
print(f"MIDI 文件的 division/PPQN = {mid.ticks_per_beat}")
for i, track in enumerate(mid.tracks):
    print('Track {}: {}'.format(i, track.name))
    for msg in track:
        if msg.type in ('note_on', 'note_off'):
            name = midi_note_to_name(msg.note, prefer_flats=True)
            print(
                f"{msg.type} channel={msg.channel} note={name} "
                f"velocity={msg.velocity} time={msg.time}"
            )
        else:
            print(msg)
```

## 元数据

Track 0 的消息全是`MetaMessage`（元消息），负责定义整首曲子的全局规则：

| 参数                                          | 含义                                    |
| ------------------------------------------- | ------------------------------------- |
| `time_signature numerator=4, denominator=4` | 拍号4/4拍                                |
| `key_signature key='Eb'`                    | 调号为降 E 大调（Eb Major）                   |
| `set_tempo tempo=750000`                    | 一个四分音符（与拍号无关）的时长为 750000 微秒（即 0.75 秒） |

## 轨道初始设置

定义轨道的音色、混响、延音踏板开关、主音量等等。

| 参数                                    | 含义                                             |
| ------------------------------------- | ---------------------------------------------- |
| `program_change channel=0 program=73` | 为通道0设置长笛音色                                     |
| `control=7 value=95`                  | 设置主音量为95（0-127），接近满音量但未拉满，为后续音符的弱力度（`pp`）留出空间。 |
| ...                                   | ...                                            |

## 音符事件

`note_on`表示按下音符，`note_off`表示松开音符，`velocity`是力度（0-127，越大越响），`time`是相对前一个事件的时间差（delta time，单位：ticks）。

| 谱面符号 | MIDI实现                                                                                                                                                                                                                                                                                                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 时间单位 | MIDI文件会定义一个`ticks_per_beat`代表一个四分音符的ticks数，而tempo定义了一个四分音符占用的实际时长，两者结合就能换算处一个tick对应的时长，这里为0.781ms。                                                                                                                                                                                                                         |
| 连音线   | 乐谱中的长连音线通过`note_on`的时间重叠实现，所以能看到`F5`的打开在`Eb5`关闭之前。                                                                                                                                                                                                                                                                                                  |
| 音符力度 | 所有音符的`velocity`在 37-46 之间（远低于 127 的最大值），对应乐谱的`pp`（极弱）力度，并且对于不同音高的音符（如`G5`和`C6`），相同音高的音符（如`Eb5`），`velocity`也会有略微调整。<br><br>一般将`ff`极强这种力度的`Velocity`定义成最大值127。<br><br>音符最终音量 = (Velocity/127) × (CC7/127) × 乐器基础音量。CC7为轨道初始设置的主音量（这里是95），一般会根据不同乐器进行调整。 |
| 三连音   | 将一拍均分成三份ticks，在这里一拍占960左右，均分后每个音符占320ticks。                                                                                                                                                                                                                                                                                                              |

# MIDI 时间转换

mido提供了`def tick2second(tick: Any, ticks_per_beat: Any, tempo: Any)`的转换接口，内部计算公式为：
$$
sec=\frac{ticks × tempo}{tpb × 10^6}
$$

因此，转为实际可执行的时间序列分两步：
1. 对midi文件的原始Message的相对ticks累加成绝对ticks：`[(绝对ticks1, 轨道0, 消息1), (绝对ticks2, 轨道1, 消息2), ...]`
2. 读取midi文件的`ticks_per_beat`、`tempo`参数，并逐个Message调用`tick2second`计算绝对时间：`[TimedMessage(0.5秒, 轨道0, 音符消息), TimedMessage(1.2秒, 轨道1, 变速消息), ...]`
