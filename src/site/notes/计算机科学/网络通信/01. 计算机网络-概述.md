# 网络结构/组成

+ **网络边缘**：主机和运行在其上的网络应用程序；
+ **接入网络**：有限或无线通信链路；
+ **网络核心**：路由器（或分组转发设备）构成的网络；



## 网络边缘

网络边缘主要就是一些主机（端系统）。主机上运行着网络应用程序。这些程序的通信方式有两种

+ 客户/服务器应用模型；
+ 对等（P2P）应用模型；



## 接入网络

基本问题：如何将网络边缘设备接入到网络核心。

接入网络非严格意义上可分为：

+ 家庭接入网络：采用数字电话线、有线电视接入。

+ 机构接入网络：基于局域网技术，端系统直接连接以太网交换机，主要用于公司、高效等组织机构。

+ 移动（无线）接入网络：无线局域网（LANs）、广域无线接入（如蜂窝网）。



## 网络核心

解决的问题：如何实现数据从源主机通过网络核心送达目的主机。

关键功能：**数据交换**。



## Internet的结构

Internet即因特网，是目前人类设计的最庞大的计算机网络系统，被称为“网络之网络”。它的特点有：

+ 端系统通过接入ISP（家庭、公司、大学ISPs）连接到Internet；
+  接入ISP也互相连接；
+ 构成复杂的网络互联的网络；
+ 动态性强，随时有网络加入，有网络离开；

这里的问题是，全球存在大大小小数以百万计的接入ISP，采用何种方案将它们连接起来？

一种方案是让各个接入ISP互相连接，但如此做成本过高。我们可以依据数据交换的思想，引入一个**全球ISP（一级ISP）**，各个接入ISP连入全球ISP——但是由于商业竞争，必然形成多个一级ISP，各个接入ISP连入其中某个一级ISP。为了实现全球联网，一级ISP也必须互相连接。

因为一级ISP并不是无处不在的，所以Internet中一些接入ISP也可能通过**区域ISP**间接连接到一级ISP。

低层ISP必须要向接入的高层ISP支付费用才能实现网络互联，为了省去这些费用，出现了**IXP**（Internet exchange point）。多个ISP网络通过IXP实现对等连接，即它们之间的通信可以不支付费用。

一些大型的公司，例如Google会自己构建网络，实现跨层级连接，这部分称为**内容提供商网络**。

# 数据交换技术

**数据交换是网络核心将数据从源主机发送到目的主机使用的主要技术**。数据交换技术中，引入了**交换设备**，主机通过连接到同一个交换设备进行间接通信，而不是主机间互相直接连接进行通信。数据交换的好处在于**减少链路数，实现数据的动态转发**。在网络规模较大的情境下，通常将多个交换设备相连形成**交换网络**，最后让主机接入最近的交换设备。数据交换技术可以分为三种：**电路交换、报文交换、分组交换**。

![计算机科学/网络通信/assets/01. 计算机网络-概述/2ef4e48798a3cb27066c8c3ba0d6f292_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/2ef4e48798a3cb27066c8c3ba0d6f292_MD5.png)





## 电路交换

最典型的电路交换网络：电话网络。电路交换分三个阶段：建立连接、通信、释放连接。

电路交换的最大特点：**独享信道资源**，线路建立后信道资源不能被第三方占用（即使双方在通话过程中都互相沉默，也不能让渡给第三者），但是这**不意味着电路交换网络中物理链路不能被共享**，事实上其可以通过多路复用技术实现共享。

![计算机科学/网络通信/assets/01. 计算机网络-概述/754c13f3f50009726161f3faa79ecc68_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/754c13f3f50009726161f3faa79ecc68_MD5.png)



## 多路复用

由于一些物理链路的传输能力（如光纤）远大于一路通信的传输需求，所以可以采用信道复用技术，提高链路利用率：

+ 将链路资源（频带、时间等）划分为“资源片”；
+ 将资源片分配给每个电路连接；
+ 每路连接独占分配到的资源片；
+ 由于独占性，资源片可能存在闲置；

![计算机科学/网络通信/assets/01. 计算机网络-概述/564a9eeae5095dd970f836a627f2b488_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/564a9eeae5095dd970f836a627f2b488_MD5.png)

多路复用技术可分为：频分、时分和码分复用。

+ **频分（FDM）**：将频带划分成资源片，例如电视频道；

  ![计算机科学/网络通信/assets/01. 计算机网络-概述/f9dd1f52c3594aa3f9d90e992846a077_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/f9dd1f52c3594aa3f9d90e992846a077_MD5.png)

+ **时分（TDM）**：将时间划分为大小相等的TDM帧，每个帧又划分为多个时隙，每个连接占用其中固定序号的时隙。每个连接的占用的时隙是周期性出现的（周期为TDM帧时长）。

  ![计算机科学/网络通信/assets/01. 计算机网络-概述/42d72b8d25fd3942f07c00ba30834c69_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/42d72b8d25fd3942f07c00ba30834c69_MD5.png)

+ **码分CDM**：广泛应用于无线通信（如蜂窝网）。
  
  + 码分复用中每个用户共用一个频带，并且时间上也不进行划分。
  + 每个用户分配一个唯一的M比特码片序列，如（-1,-1,1,1）其中-1表示二进制0，1表示二进制1。
  + 所有用户某时发送的序列会叠加。
  + 各用户码片序列相互正交，才能区分出不同用户的数据序列。
  + 编码结果是数据序列和用户码片序列的运算结果。



## 报文交换

数据以报文的形式作为一个整体进行传输，一个网络节点必须等到整个报文接收完全后才能转发至下一个节点，也必须等到整个报文被转发出去后才能接收新的报文。



## 分组交换

分组是报文拆分出来的一个个小的数据包。一个分组通常由头和数据本身组成，就像一封信有信封和信纸组成一样。

分组交换相对于报文交换来说，多了报文的拆分和重组过程，这就导致了额外的开销。但是分组交换带来的好处是：一个节点在转发一个分组时，可以继续接收新的分组。



## 报文交换VS分组交换

报文和分组交换都采用**存储-转发**方式，即一个节点先将数据存储下来，再转发出去。

+ 报文交换：以完整报文进行存储-转发；
+ 分组交换：以较小的分组进行存储-转发；

报文交换VS分组交换：

+ 当链路中存在多个节点时，分组交换可以**并行传输**分组，而报文交换是串行的。
+ 分组交换中每个路由器节点的缓存需求要远小于报文交换，因为前者不需要存储整个报文。

现代网络普遍采用分组交换方式。



## 电路交换VS分组交换

分组交换相对于电路交换来说，并**没有事先就占用资源**，而是一种的动态分配。网络中用户通常处于非活动状态，电路交换中，即使用户处于非活动状态，链路也不会被释放。例如1MB/s的链路，每个用户活动时的带宽为100KB/S，那么电路交换可以支持10个用户；而分组交换中，用户错峰上网，理论上可以支持上百个用户（这是一个概率问题），当链路中只有一个用户时，该用户就可以独占全部资源。

但是分组交换并不是绝对优于电路交换的。**分组交换更适合于突发网络访问**，提高资源共享率，并且无需呼叫建立，较简单；但分组交换可能会出现**拥塞**现象，电路交换则可以保障高质量的实时数据通信。





# 性能描述

+ **速率**：单位时间传输的比特数（信息量）。

+ **带宽**：通信领域中指最高频率和最低频率之差；网络领域中指数字信道所能传输的最大速率。

+ **时延（延迟）**：延迟可分成四类，

  + 节点**处理延迟**：差错检错、确定输出链路导致的延迟，通常小于毫秒级；
  + **排队延迟**：路由器在转发其他分组，导致当前分组在缓存中排队等待的延迟，严重取决于路由器的拥堵状态；
  + **传输延迟**：等于分组比特数/链路带宽（分组被传输出路由器后就可以看做0长度的数据）。
  + **传播延迟**：和链路的传播速度和长度有关，和分组长度无关。

+ **时延带宽积**：等于传播时延*带宽，其意义为从发送第一个比特起到该比特到达目的地的这段时间内，链路上总共容纳了多少比特。

  ![计算机科学/网络通信/assets/01. 计算机网络-概述/c66e7bb90b65d79e7dcb3495feae8486_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/c66e7bb90b65d79e7dcb3495feae8486_MD5.png)

+ **丢包**：路由器缓存有限，分组到达已满队列时被丢弃。
+ **丢包率**：等于丢包数/已发分组数。
+ **吞吐量（率）**：在发送端到接收端之间传送数据速率。

### 应用层

应用层是网络应用程序以及它们的应用层协议存留的地方，支持用户通过网络代理（如浏览器）或网络接口使用网络。位于应用层的数据分组称为**报文**。

### 会话层

### 数据链路层

![计算机科学/网络通信/assets/01. 计算机网络-概述/f737f3935758966532fab1784b85bca3_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/f737f3935758966532fab1784b85bca3_MD5.png)

解决了物理链路**直接相邻**的两个节点之间**数据帧**的传输。

+ 组帧：加头加尾构造一个数据帧，其目的在于让接收端从比特流中切分出每一个帧。

+ 物理寻址：在帧头中增加发送端和接收端的物理地址标识。

  ![计算机科学/网络通信/assets/01. 计算机网络-概述/edd64e167ccdc3e2c5c1faa068df9c1a_MD5.png](/img/user/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A7%91%E5%AD%A6/%E7%BD%91%E7%BB%9C%E9%80%9A%E4%BF%A1/assets/01.%20%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C-%E6%A6%82%E8%BF%B0/edd64e167ccdc3e2c5c1faa068df9c1a_MD5.png)

+ 流量控制：匹配发送端和接收端的速度匹配，避免发送端发送太快，淹没接收端。

+ 差错控制：检测并重传损坏或丢失帧，并避免重复帧。

+ 访问控制：在任意时刻决定哪个设备拥有链路（物理介质）使用权。

+ 接口特性：规定了机械特性（插口形状）、电气特性（电平）、功能特性（引脚功能）、规程特性（工作过程）。

+ 数据率（百兆、千兆网络）。
