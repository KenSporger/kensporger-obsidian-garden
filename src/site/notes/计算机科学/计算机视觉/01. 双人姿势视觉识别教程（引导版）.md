# 第一部分：教程简介

## 🎯 这份教程能让你做出什么？

想象一下：

👫 你和朋友站在电脑摄像头前，不用键盘、不用MakeyMakey复杂的连线，只需要做动作——你抬左胳膊，屏幕上的红色坦克就左转；朋友下蹲，蓝色坦克就前进。

这就是双人姿势视觉识别！学完这份教程，你就能把任何单人游戏变成双人体感游戏。

## 📋 学完这份教程，你会收获：

> [!NOTE]
> 
> 1. 通过与AI对话，完成多人姿势视觉识别的技术选型；
> 2. 实现双人姿势的视觉识别；
> 3. 将单人游戏升级为双人游戏；

## 🧑‍🏫 这份教程适合谁？

在开始之前，先确认一下你已经准备好了：

- 我用 TRAE 或 WorkBuddy 做过游戏（Vibe Coding 我懂！）
- 我用 MediaPipe 做过单人的动作识别（比如抬臂、深蹲）
- 我想做的游戏需要两个人一起玩（对抗或合作都可以）

都打勾了？ 太棒了，开始吧！🚀

功能演示：[https://dual-pose-detect.sg.superbrain-ai.com/](https://dual-pose-detect.sg.superbrain-ai.com/)



# 第二部分：向AI提问，了解技术


在WorkBuddy或者TRAE（Chat模式）向AI提问如何实现多人的视觉姿势识别，你可以这样问AI：

| 想要了解的     | 可以这样问AI                                                                                                                       | 备注                                        |
| --------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| 1. 确认可行性  | 我现在已经使用TRAE/WorkBuddy开发出了可在浏览器中运行的单人游戏，使用普通电脑摄像头，基于MediaPipe Pose技术识别了一些单人的动作。现在想将游戏改进成双人游戏，MediaPipe 能支持双人吗？如果能，具体应该用哪个 API？ | 1. 可以说明具体是哪些动作  <br>2. 可以描述游戏的机制          |
| 2. 对比技术方案 | 除了 MediaPipe，还有哪些可以在浏览器端实现多人姿态识别的方案？请从「易用性」「特征点数量」「多人稳定性」「延迟」「适合场景」几个维度帮我对比一下                                                 |                                           |
| 3. 方案选型建议 | 我的项目目标是：开发一个双人运动游戏，需要同时识别两个人的动作，用于游戏中的攻防判定。基于这个场景，你推荐哪种方案组合？为什么？                                                              | 1. 可以把你的技术水平描述一下。  <br>2. 可以描述游戏需要识别的具体动作 |
| 4. 技术挑战预判 | 如果采用MediaPipe PoseLandmarker方案，在双人场景下可能会遇到哪些技术挑战？有什么样的应对策略。                                                                   | 1. 方案名字换成自己的                              |
| 5. 集成方法   | 如果采用MediaPipe PoseLandmarker方案，整体技术架构应该是怎样的？需要哪些库和依赖？                                                                         | 1. 方案名字换成自己的                              |

## 🛠️ 第1步：让摄像头识别两个“火柴人”

TRAE切换到Build模式：

```Plain Text
1. 请用MediaPipe PoseLandmarker方案写一个基础demo，调用笔记本摄像头，实时识别两人的身体骨架，并实现左右手抬臂动作，并描述动作判断的逻辑
```

可以将你游戏的动作需求加入到这个Demo中。


## 🧠 在继续之前，先搞懂这4个问题

相比于单人的Mediapipe识别，双人姿势特征点有何不同呢？可以这样问AI：

```Plain Text
请帮我找到代码中处理“哪个点是玩家1、哪个点是玩家2”的部分，并解释：
1. 系统是怎么区分两个人的？
2. 如果画面里只有1个人或者来了3个人，会发生什么？
3. 如果一个是大人一个是小孩，识别会有什么不同吗？
4. 如果两个人交换位置，系统还能认出谁是谁吗？
```

跟AI聊完这4个问题，你会对双人识别更心里有底。

✅ 这一步的终点：你能用自己的话解释“系统是怎么区分两个人的”。


## 🔍 第2步：评估和优化识别结果

可以从以下维度来评估识别和优化结果，将不满意的地方告诉AI，让AI提供解决方案。

| 评估点           | 怎么做                  |
| ------------- | -------------------- |
| 动作幅度要多大才能触发？  | 深蹲从小幅度到大幅度，看到哪个幅度才触发 |
| 高矮胖瘦会影响识别吗？   | 对比两个身高不同的人做同一动作的膝盖角度 |
| 站着不动时骨架会抖吗？   | 两人保持静止，观察关键点是否稳定     |
| 交换位置后标签会换错吗？  | 两人交错行走，观察ID是否互换      |
| 会把其他人或东西认成人吗？ | 画面中加入椅子、假人等，看是否误检    |
| 光线变暗时还能看清吗？   | 拉上窗帘对比开窗时的识别效果       |
| 快动作会被漏掉吗？     | 连续快速做3个动作，看计数是否完整    |
| 身体被裁掉时能补全吗？   | 站到画面边缘，看骨架是否仍完整      |
| 识别准确率怎么算？     | 做10次动作，统计识别对了几次      |
| ...           | ...                  |
