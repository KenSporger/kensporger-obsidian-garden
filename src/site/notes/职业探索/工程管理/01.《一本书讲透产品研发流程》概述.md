# V模型
{ #76934d}


融合了机械、电子、软件的产品其研发流程通常符合V模型。它的精髓在于同时考虑了时间和空间因素。在V模型的左半阶段，是从整体到局部的过程，即从总体方案设计到子系统设计，再到详细设计，工作范围逐渐缩小；而在右半阶段，是从局部到整体，范围从小到大的过程。
