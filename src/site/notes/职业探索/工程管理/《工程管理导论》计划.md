# 组织环境分析

组织的环境氛围**外部环境**（不可改变的）和**内部环境**（自身可改变）。
+ 外部环境
{ #b1b283}

	+ **一般环境因素**：对社会中所有企业、组织都有影响的因素，包括政治、经济、法律、社会文化、技术、国际...
	+ **特殊环境因素**：与企业生产经营直接相关的，包括供应商、顾客、竞争对手、政府团体等
+ 内部环境：物力、财力、人力、信息资源等。


# 产品生命周期分析
{ #fd2c0b}


用于分析**产品或者行业的成长性**。

![image.png](/img/user/%E8%81%8C%E4%B8%9A%E6%8E%A2%E7%B4%A2/%E5%B7%A5%E7%A8%8B%E7%AE%A1%E7%90%86/assets/%E3%80%8A%E5%B7%A5%E7%A8%8B%E7%AE%A1%E7%90%86%E5%AF%BC%E8%AE%BA%E3%80%8B%E8%AE%A1%E5%88%92/image.png)

+ **投入期**：产品刚进入市场，还未被用户接受，销量增长缓慢，企业投入大量广告宣传，企业盈利少甚至亏损；
+ **成长期**：产品试销成功后转入大批生产，由于**规模经济效应**，产品成本显著下降，利润明显上升，同时也吸引了大量竞争者；
+ **成熟期**：市场趋于饱和，无新用户进入，市场竞争最为激烈，企业为了提高市占率投入大量营销费用，利润触底并下降；
{ #04d054}

+ **衰退期**：产品逐渐失去消费者，企业转向生产其他产品，产品寿命周期宣告结束；

# 五力模型
{ #7575b4}


波特提出的五力模型可用于企业的**竞争环境分析**。
![image-1.png](/img/user/%E8%81%8C%E4%B8%9A%E6%8E%A2%E7%B4%A2/%E5%B7%A5%E7%A8%8B%E7%AE%A1%E7%90%86/assets/%E3%80%8A%E5%B7%A5%E7%A8%8B%E7%AE%A1%E7%90%86%E5%AF%BC%E8%AE%BA%E3%80%8B%E8%AE%A1%E5%88%92/image-1.png)

### 现有竞争者能力

主要研究的内容包括：
+ 行业内竞争的基本情况；
+ 主要竞争对手的实力：销售增长率、市占率、产品获利能力；
+ 竞争对手的发展方向：产品开发动向、市场拓展或转移动向；
一般出现以下情况时，同行竞争者的竞争会加剧：
+ 市场处于[[职业探索/工程管理/《工程管理导论》计划#^04d054\|成熟期]]；
+ 同质化产品和服务；
+ 行业退出壁垒较高：在重资产的行业，由于设备的专用性，企业退出壁垒可能高于继续竞争的压力；
+ 行业进入壁垒较低；

## 潜在竞争者进入能力

潜在竞争者进入的能力强弱主要取决于两个因素：
+ 潜在竞争者本身的综合实力以及现有企业可能作出的反应；
+ 行业进入门槛的高低；

## 替代产品威胁能力

替代品不仅仅指拥有同类功能的产品，也包括有相似功能产品带来的威胁。替代品实际上是通过规定某个行业内企业可能获利的最高限价来限制该行业的经营行为和潜在收益的（如果定价较高，用户就会转向替代品）。

## 供应商的谈判能力

影响供应商的谈判能力的因素有：
+ 双方的规模大小：供应商规模大，企业规模小时，供应商的谈判能力强；
+ 供应集中程度：供应商为很多买主供货，以致单个买主的谈判能力较弱；
+ 供应替代的成本：如果企业很难找到其他的供应商，那供应商的谈判能力就强；
+ 供应商前向一体化的可能性：若上游供应商能向下游产品扩张，那供应商的谈判能力就强；
+ 企业后向一体化的可能性：若企业向上游原材料扩展，那供应商的谈判能力就弱；

## 客户的谈判能力

这里的客户包括C、G、B端。影响客户谈判能力的因素：
+ 所有供应商的谈判能力的因素（反过来）；
+ 客户在企业产品销量中的比重：若比重过大，那么客户的谈判能力强，因此企业要尽量摆脱对少数大客户的依赖；
+ 需求潜力：总需求研究、需求结构研究、用户购买力研究；

需要注意的是，很多企业是双重身份，即是客户又是供应商。

## 局限性

五力模型包含一些假设的局限：
+ 同行没有合作关系；
+ 行业规模固定，只有夺取对方份额才能有更大市占率；
而在实际中，同行可以通过合作，一起把市场蛋糕做大。
