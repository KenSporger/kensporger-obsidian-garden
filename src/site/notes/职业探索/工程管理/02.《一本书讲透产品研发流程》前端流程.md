前端流程的目的是确保产品研发方向正确，符合市场和客户的真实需求。
# 分析步骤与产物

前端流程按照执行顺序包括四个部分：
+ **宏观市场分析**
+ **细分市场分析**
+ **战略定位分析**
+ **产品规划**
分析的输出物为：市场分析与策略、产品规划图。

# 宏观市场分析

对整个行业发展的总体情况进行研究，主要研究与企业生产经营相关的宏观环境因素（政治、经济、社会...）。

# 产品规划

需要进行产品规划的原因：
+ 不同产品之间存在先后实现的逻辑关系；
+ 根据企业自身实力，优化资源配置，如选择先推出低端产品还是高端产品；

## 7+2+1原则

在产品（需求）排序中，可以参考：70%的聚焦项目（能持续造血）、20%的重大突破项目（目前利润不高但有市场潜力），10%的新布局项目（短期难以盈利，长期有巨大价值）。


## 自下而上，自上而下

对于大型的企业，产品规划的方法一般先采用自下而上法：下级产品部门更清楚自己的资源和产品实现可行性，由他们先产品规划内容，然后高层规划部门根据各个产品部门的规划进行评估、沟通，从全局视角出发进行调整或整合，形成企业层面的产品规划。最后，通过自上而下法将规划下发到各个产品部门执行。

对于小型企业而言，组织层级少，高层对基层情况较了解，可以直接采用自上而下法。

## 产品路线图

即RoadMap图，包含时间、产品型号、主要特性。

![职业探索/工程管理/assets/02.《一本书讲透产品研发流程》前端流程/image.png](/img/user/%E8%81%8C%E4%B8%9A%E6%8E%A2%E7%B4%A2/%E5%B7%A5%E7%A8%8B%E7%AE%A1%E7%90%86/assets/02.%E3%80%8A%E4%B8%80%E6%9C%AC%E4%B9%A6%E8%AE%B2%E9%80%8F%E4%BA%A7%E5%93%81%E7%A0%94%E5%8F%91%E6%B5%81%E7%A8%8B%E3%80%8B%E5%89%8D%E7%AB%AF%E6%B5%81%E7%A8%8B/image.png)

产品路线图是产品规划的呈现结果，但其背后还需要许多配套的资源（人力、物力、财力）和策略（销售、宣传）支持。因此，在输出产品路线图之外，附带应该有各种资源的分析和相应的策略输出。

其次，产品路线图需要定期根据企业和环境情况进行更新。
