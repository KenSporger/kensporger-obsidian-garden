# 管理人员招聘渠道

管理人员采用外聘和内部选拔提升两种方式的优缺点如下：

| 方式   | 优点                                                            | 缺点                                                                      |
| ---- | ------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 内部选拔 | 1. 组织对选聘者的能力有充分的评估；<br>2. 选聘者对组织情况比较了解，适应快；<br>3. 调动组织成员的积极性； | 1. 近亲繁殖；<br>2. 内部竞争，激化成员之间矛盾；<br>3. 短期内可能没人满足条                          |
| 外聘   | 1. 引入外部视角，为组织带来新鲜空气；<br>2. 缓和内部竞争；                            | 1. 外聘者对组织情况不熟悉，缺乏人事基础，需要比较长的适应时间；<br>2. 组织对应聘者能力了解有限；<br>3. 内部员工积极性受到打击 |

# 管理者的核心职责

1. **目标引领与战略落地**：承接组织整体战略，将目标分解到团队及个人，明确工作方向与标准，确保下属行动与组织目标一致；在动态环境中校准团队工作方向，适配内外部环境变化。
2. **下属激励与能力赋能**：掌握激励理论，通过物质/非物质激励调动下属工作积极性；识别下属成熟度与能力短板，提供指导、培训与成长机会，提升团队整体能力。
3. **团队建设与冲突管理**：打造协作型团队，融合正式组织与非正式组织的价值，引导非正式组织服务于组织目标；识别并管理组织冲突，区分建设性 / 破坏性冲突，采用回避、强制、迁就、折中、合作等策略化解矛盾，营造积极的团队氛围。
4. **情境适配与权变决策**：依据组织情境（上下级关系、任务结构、职位权力）、下属成熟度等因素，灵活调整领导方式；在团队工作中做出及时、合理的决策，解决工作中的问题与障碍，为团队提供资源与支持。
5. **变革创新与组织发展**：作为变革型管理的核心主体，敏锐感知内外部环境变化（市场、竞争、技术等），推动组织变革与创新；打造学习型组织，激发组织创新力，推动团队从 “维持现状” 向 “持续进化” 转变。
6. **自我管理与榜样示范**：作为团队的核心标杆，保持自身行为的一致性与规范性，践行组织价值观；做好自我情绪管理与压力调节，以稳定的状态带领团队应对挑战，同时承担团队工作的最终责任。

领导者任务清单：

+ 在工作、生活中**发现机会**；
+ 运用专业知识和技能**解决问题**；
+ 透过社会网络、人际交互**获取支持**和资源、扫除障碍。
+ **平衡心态**，面对成功、失败、诱惑、威胁、不确定性乃至各种压力，降低或消除负面影响、降低或消除负面链式反应，保持情绪稳定和韧性，保持乐观和希望。
+ **强健体魄**，保持旺盛的体能。
+ 通过学习、研究，推动**持续成长**。
+ 为身边以及远远近近的人**提供支持**。（在做到前面的基础上）

# 领导力的特质

## 基础管理技能

根据不同管理层级，分别具有对应水平的技术、人际、概念技能。

+ **技术技能**：掌握所在专业领域的工作程序、技术、知识与方法，能指导下属完成具体作业工作。
+ **人际技能**：理解、激励他人并与他人共事的能力，包括共情、沟通、团队协作、冲突化解等，是搭建良好上下级 / 同事关系的核心。
+ **概念技能**：综观全局、洞察组织与环境要素间相互影响的能力，包括战略思维、系统思考、决策能力。

## 通用素养与能力

1. **权变适配能力**：无绝对 “最好” 的领导方式，需根据情境（上下级关系、任务结构、下属成熟度）灵活调整领导风格，避免僵化。
2. **情绪管理与韧性/正念觉察力**：面对成功、失败、压力与不确定性时，保持情绪稳定，降低负面情绪的链式影响；具备抗挫折能力，能快速从困境中恢复并带领团队寻找新机会。
3. **共情与关怀能力**：从 “经济人” 假设转向 “社会人”“自我实现人” 假设，关注下属的心理需求与情感体验，c。
4. **权力运用能力**：掌握领导者的法定权等权力类型，合理运用职权开展管理，同时通过个人魅力（非职权）增强团队凝聚力，避免单纯依靠职权进行强制管理。
5. **学习与反思能力**：持续吸收新知识、新方法，总结工作中的经验与教训，不断提升自身的领导能力，适配组织发展的需求。

# 领导力画像

## 最难共事者者模型

**核心观点**：领导的有效性取决于领导风格与情境的匹配、不存在永远都好的领导分割。**不建议去改变一个领导者的风格，而是改变情景以适应领导者 or 为情景选择领导者**。

最难共事者（LPC）问卷用于判断领导者的风格类型。

- **任务导向型（低 LPC 分）**：以完成工作任务为核心，行为特征是指令清晰、流程规范、注重效率；**适用场景**：情境极为有利（上下级关系好、任务结构明确、职位权力强）或极为不利（上下级关系差、任务结构模糊、职位权力弱）。
- **关系导向型（高 LPC 分）**：以维护团队关系为核心，行为特征是注重沟通、共情下属、打造协作氛围；**适用场景**：情境处于中间状态（如上下级关系好但任务结构模糊、职位权力中等）。


## 领导寿命周期模型

**核心观点**：下属成熟度（包括知识、技能的工作成熟度、做事意愿与动机的心理成熟度）调整领导方式。

- **命令式（高工作 - 低关系）**：适用于下属成熟度极低的场景，领导者下达具体、明确的指令，直接指挥下属的工作，无需过多的沟通与关怀。
- **说服式（高工作 - 高关系）**：适用于下属较不成熟的场景，领导者在下达指令的同时，向下属解释工作的原因与意义，通过沟通获得下属的认同。
- **参与式（低工作 - 高关系）**：适用于下属比较成熟的场景，领导者减少对工作的直接指挥，与下属共同决策、参与工作规划，注重倾听下属的意见。
- **授权式（低工作 - 低关系）**：适用于下属高度成熟的场景，领导者将工作决策权与执行权完全授权给下属，仅对工作结果进行监督与把控。
