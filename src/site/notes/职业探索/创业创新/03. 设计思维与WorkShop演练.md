本堂课由上海黄浦区环保志愿者促进会会长——三多老师为我们讲解设计思维，以及通过一个WorkShop来构建用户画像，拟定创新议题。

# 设计思维

**设计思维**是一种以人为目的、以人为本的思维，通过**共情->定义**（这两步是为了捕捉用户的痛点）**->设想->原型->实验**（这三步是为了提供解决方案）来创造突破性的想法。例如：核磁共振是孩子最害怕的检测，要在里面待15分钟，但是有人通过设计思维将核磁共振仪器改造成了海盗船主题，使得儿童镇定剂比例从80%降低到了10%。

# WorkShop

WorkShop的讨论形式，是一群人围绕一个具体难题，一边讨论一边用笔绘制，最终形成一个解决方案。一个WorkShop的典型特征如下：

+ **全员参与**，人人都要发挥想象力进行发言；
+ 偏好打破部门、岗位壁垒，把**不同视角**的人组合在一起；
+ 弱化层级，**平等表达**，一般管理者、资深员工延后发言；
+ 人数规模在4-10人为佳；
+ **采用围站式，使用白板或海报纸、多色马克笔、彩色便利贴**，用于随时记录想法，重组、归类；
+ **延迟评判**，发散创意阶段，禁止否定、反驳、吐槽，收敛阶段再评估可行性；
+ 流程普遍遵循**梳理问题 → 发散创意 → 筛选收敛 → 方案成型**；
+ 通常结合**设计思维、头脑风暴、逆向思考、角色换位**等思维方式；
+ 成果即整张写满文字、图画、便利贴的白板 / 海报纸，会后无需过多整理；
+ 整体时间通常在1-2h左右；

# 课堂练习

课堂上，每个小组针对某一个社会问题进行了设计思维+WorkShop的实践练习。

## 共情

设计思维的“共情”前提是对用户进行了访谈，或者收集了相关的资料。

如下图所示，首先明确讨论的用户对象（可以有多个，例如刚退休，不知道退休生活如何安排的老人），然后针对该用户，列出关注的场景（如娱乐、出行、社交三个场景），以及该场景下的痛点（娱乐场景下，饭后空余时间没有规划，只能刷手机看电视）、建议（有更多适合老人的娱乐产品和服务）以及期待的改变（生活更充实）。

在完成发散之后，需要进行问题收敛：从多个用户中选择一个用户（可以是结合后的），从多个场景和痛点中选择一个（某一列），并给出洞察（刚退休的老人生活单调，找不到方向和价值）。

注意**洞察是问题背后的问题**，比如就医困难是问题，但是洞察是什么导致了就医困难，例如各家医院的就医流程不同。

## 定义

接下来是进行议题的确定：我们可以如何为（上个步骤选定的目标用户）解决（上个步骤的洞察）的问题，以实现（上个步骤的期待）的目标。

## 设想

为了寻找议题的解决方案，小组人员进行头脑风暴，过程中需要遵循：
+ 禁止批评，不评判
+ 追求数量，越多越好
+ 鼓励天马行空、脑洞大开
+ 借题发挥，组合优化
+ 人人平等，不分高低
+ 一次只说一个，过程中不打断
如果思想枯竭，可以引入一些随机身份（如自己是导游、手艺人会有什么新的方案）、产品服务呈现形式进一步激发灵感。
