![08751db6753fe5c3555f41a820a59416_MD5.png|326](/img/user/%E8%81%8C%E4%B8%9A%E6%8E%A2%E7%B4%A2/%E5%88%9B%E4%B8%9A%E5%88%9B%E6%96%B0/assets/02.%20%E6%85%88%E5%96%84%E6%8D%90%E8%B5%A0%E4%B8%8E%E7%BE%8E%E7%88%B1%E8%9E%8D%E5%90%88%E7%BB%84%E7%BB%87%E5%88%86%E4%BA%AB/08751db6753fe5c3555f41a820a59416_MD5.png)

老师带来了几个视障疾病模拟眼镜，让几位同学戴上后认一些颜色和文字，让我们了解不同视障疾病的表现：
+ 只有特定视角才能看到东西（青光眼）；
+ 一片模糊（白内障、高度近视）；
+ 有各种色斑干扰（视网膜病变）；
B站也有[视频]( https://www.bilibili.com/video/BV1Rx4y1o7zF/?share_source=copy_web&vd_source=b1e9d90375317ee28de624f2366c389f)可以第一人称视角来体验这些疾病。很多视障人士并非完全失明，低视力要占到70%左右，有一些人看上去甚至像正常人一样，这些人在外问路时就特别容易被误解（帮助人会指往哪个方向走，但是对方根本看不见）。

# 美爱融合组织

上海美爱融合艺术公益发展中心，由于欢发起于2017年，专注于视障青少年艺术教育，并借助艺术力量，深耕新大众文艺实践，传承红色文化，促进残健融合，倡导无障碍环境建设理念。2021年，通过中国社会组织评估3A等级（有效期5年）。

“美爱”二字，源自“May I Help You”。

+ **使命**：创建平台，开发潜能，让视障者有尊严地生活
+ **宗旨**：以艺术为媒，以融合为旨
+ **价值观**：奉献 开拓 融合 共创
+ **愿景**：成为视障青少年的梦工厂

视障群体需要有一些事情去做。虽然国家有要求企业按比例为视障群体提供就业，但是大多情况企业是招了他们，但是会让他们回家呆着，即使真正能够干活，其职业发展的成长也很受限。

因此，美爱融合为视障群体探索过音乐、手工等等方式。

## 不靠谱乐队

由爱美融合组建的一支视障人乐队。字面意思，不看乐谱。2022年，以不靠谱乐队为原型的公益院线电影《奇迹乐队》开机，于2023年10月进行了近百场点映。

## 陪你看世界

"陪你看世界”项目是为视障和健视伙伴们设计各类融合实践项目，进行企业参观、社会实践、沉浸式体验、融合出游等丰富多彩的活动。目前是组织视障人群勇敢走出家门，体验世界（很多视障人群常年活动的范围极其有限）。

# 我们能做的

软件、APP、硬件产品应该要关注无障碍设计，例如市面上的VR眼镜基本没有考虑过低视人群的设计，成像都没有直接看手机来得大。而苹果系统的无障碍做得是比较好的，官方有出无障碍的文档指南。

APP的更新可能会导致操作逻辑变化，或者无障碍体验退化，所以视障人士会倾向于保留旧版本APP。

所有为盲人特定设计的产品最终能存活下来的只有盲棍、盲人笔，大多做到最后都无疾而终。

最后是如何正确地帮助视障人士引路？
+ 错误1：直接拽着盲棍带路；盲棍相当于是盲人的视线延长，是不能去阻碍的；
+ 错误2:  面对着视障人士，为他看路；自己背着走路会撞到东西；
+ 正确的：让视障人士握着自己的右手手肘前进。
