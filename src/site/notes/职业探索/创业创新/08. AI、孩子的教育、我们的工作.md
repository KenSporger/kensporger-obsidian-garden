写这篇文章，是想整理过去一年我对AI发展的思考，探讨在这样的时代浪潮下，我们——以及我们的孩子——该何去何从？

# AI与工作

目前，大部分的科技公司都在尝试产品开发流程的新范式：业务提需求给AI，AI去设计和实现，AI进行验收。下面是某家企业的内部规划：

> [!NOTE] AI研发能力建设
> AICoding工具已覆盖90%的研发人员，目前前端团队迭代速度很快，后端团队也在逐步跟进。对于标准化、无复杂业务逻辑的场景，AI已能很好地完成任务。但对于有复杂业务逻辑、历史包袱重的代码仓库，AI编码仍面临明显瓶颈。
> 
> 业界正在形成共识:问题的根源不是A!模型能力不足，而是缺少足够准确的上下文。Spec-Driven Development(规格驱动开发)正在成为行业标准实践--通过结构化的规格说明为AI提供明确的需求、技术约束和项目上下文。我们将围绕这一模式构建能力体系。
> 
> 以一个典型的需求交付流程为例说明新模式的工作方式:研发工程师接到需求后，在Spec管理平台选择对应的需求单，平台通过MCP自动从需求平台拉取需求描述、原型图、设计图等物料，并通过研发知识库获取相关代码和业务上下文。在需求澄清阶段，AI会针对不清楚的部分与研发进行多轮对话，研发需要不断输入自己的想法和决策，最终形成清晰完整的需求理解。接下来，AI完成架构设计、API设计、数据库设计，生成相应的Spec文档并进行校验。基于这些文档，系统生成具体的任务列表，AI按照任务列表和Spec生成代码，研发完成联调测试后提交。代码上线前还会通过AI自动化测试进一步保障可靠性。
> 
> 在这个模式下，研发的代码实现工作会减轻，架构设计和代码评审工作会加重。这样做的好处是既能提升开发效率，也能提升交付质量。

如果这个计划成功落地，整个公司的研发都要砍一半以上。AI带来的“研发效率提升”并不会降低研发人员的工作量，因为资本本质就是榨取剩余价值：不会AI的员工将被淘汰，剩余的“精英”们原来每天做一个需求，现在要用AI做3个需求。

学术界的日子也不好过，AI for science目前的现状是：
+ 导师的指导没有AI来得好用；
- openai、anthropic每隔几个月，悄无声息地，把整个领域的天花板往上掀一层。普通博士的研究赶不上它的速度；
- 研究人员发现自己和人的沟通失去了价值，因为和AI对话效率更高；

针对这样的现状，一篇[知乎文章](https://zhuanlan.zhihu.com/p/25944473389)从AI能力发展的三种情形和成本角度，分析了AI是否会导致人类大规模失业，提出了几个值得深思的观点：
+ AI摧毁整个产业链，链上的资本家都会有失业风险；
+ 市场需求的增加，但是AI提升生产率的速度会高于市场需求；
+ 人类转换岗位的学习过程是缓慢的；
+ 认为AI会出错，那只是AI技术发展木桶效应；
+ AI发展的趋势无法阻挡；

不过，并非所有人都感到悲观。在和同学们探讨“AI是否会使我们失业”的话题（注意，并不是“AI替代人类”，这是两个完全不同的问题）时，我发现一个有趣的现象：**大家对这个问题的态度，很大程度上取决于其职业背景**。程序员普遍显得焦虑，相当一部分人在着手转向Agent开发岗；而AI研究员、企业的管理者和创业者，则相对乐观。

乐观者最常引用的论据是：AI会催生一批全新的职业。然而，事实果真会如此吗？

> [!NOTE] 两匹马的讨论
> 1900年，两匹马凝视着早期的汽车，思考着它们的未来。
> 
> “我很担心技术性失业。”
> 
> “嘶嘶，别做个卢德分子。当年马车被发明的时候，我们的祖先也说过同样的话。但今天，我们的就业岗位不减反增，而且，这些岗位比过去更好，我宁愿拉一辆轻巧的四轮马车，也不愿整天原地打转，只为了驱动一台愚蠢的矿井抽水机。”
> 
> “但是，如果内燃机真的腾飞了呢？”
> 
> “我肯定，一定会有超出我们想象的新工作给我们来做。过去一直都是这样的，就像轮子和犁发明的时候一样。”

但我们都知道，那些“超乎想象”的新工作从未降临到马儿身上。那些没有实用价值的马匹被成批淘汰，马匹数量从1915年的2600万匹缩减至1960年的300万匹。

即便新职业确实会出现，且数量足够庞大，也必须正视一个事实：这些职业并非一夜间涌现；在新岗位陆续“发明”的过程中，旧岗位的大规模失业已然同步发生。**这意味社会必将经历一段长达数年乃至数十年的阵痛低谷期**。

这样情景可以用一幅“人类能力地形图”来直观地描绘（图中的海平面在2026年看来已明显过时）。海拔代表机器完成各项任务的难度，而不断上升的海平面则标示着机器已能胜任的领域。就业市场的主流趋势，并不是“我们正全面转向崭新的职业” ，而是**我们都在挤向未被技术潮水没及的高地。但这些地方空间有限，越多人的涌入意味着大家分到的果实也会越少。**

除了被动失业之外，还会有更多的人（包括我在内）无法从当前的工作中汲取成就感，对自己的职业发展感到迷茫。以软件开发为例，过去许多程序员能在Coding中进入心流状态，从中获得满足；可当AI接管了大部分编码工作，程序员退化为“代码审核员”后，那种创造的愉悦便被剥夺了。

更何况，AI的能力仍在指数级增强，某些岗位被完全替代，似乎只是时间问题。那么，在明知自己终将被替代的前提下，当下从事这份工作的意义何在？当然，你可以选择拥抱新技术，终日疲于追逐AI圈层出不穷的新概念，但你学习的驱动力究竟来自哪里——仅仅是让自己在职业市场上变得更有竞争力吗？

# AI与人脑主体性

最近有一个让我非常反感的现象：很多同学在课上汇报时候使用的都是NotebookLM等AI生成的PPT。风格单一、不真实、无重点，看起来实在索然无味。更有一次，我在做PPT的时候，旁边一位同学说道：“现在居然还有人用古法做PPT啊？”。平心而论，当下AI生成的PPT还谈不上及格，要做到优秀还是要靠主动构思以及手工细节打磨。

这个现象反映的正是AI对人脑主体性的侵蚀。对AI的过度依赖，会导致记忆力、思考能力的下降，以及对真实人际沟通的远离倾向。

# AI与孩子们

上周访谈两位同学时，我们幼儿园孩子对豆包的严重依赖：它既能提供情绪价值，又会不断延伸话题，能让孩子聊上一个小时；最大的问题是会生成一些不适合儿童的内容（通过豆包都能刷短视频了）和建议。遗憾的是，各大模型厂商至今仍未推出分龄版本的AI大模型。

这一代的孩子，是人类历史上第一批在算法、社交媒体与人工智能的共同哺育下成长起来的原住民。他们似乎拥有了更富足的世界、更自由的表达、更开阔的视野，却也面临更严重的心理问题，成因包括但不限于：
+ 容易被安稳的生活困住，没有足够的受挫机会让孩子成长（受挫失败是最好的老师）；
+ 社交媒体和AI成为了孩子成长的塑造者和参与者，在孩子还没产生“我想要什么”的念头时，来自网络的答案和图像就已经塞过来了；
+ 沉溺于AI（比如对手机、豆包过分依赖），亲子互动减少。
+ AI能做很多事情了，不知道学什么才是正确的，找不到人生的一个方向；
+ 应试教育无法与AI时代适配；
+ ...

由此看来，城市里的孩子，更像是AI时代的困境者；而乡村的孩子，究竟该走出大山，还是守住自己的净土，追寻自我的认同，同样成为一个社会问题的问题。

# AI与创业

OPC（一人公司）近来被热炒，AI真的为个体撕开了无数创业的窗口吗？恐怕未必，AI可能只是少数派的机会，要抓住AI的机遇，首先要想做到三件事情：

- 知道自己热爱什么、擅长什么
- 清楚市场需要什么？
- 成为细分领域的专家

遗憾的是，大多数人连第一件事情都没有想明白。

在就AI技术本身来说，投资圈早已对“AI+X”的项目流露出倦怠与审慎，双创赛场上，拥抱AI的项目比比皆是，但细究之下，大多悬浮于概念之上，无法落地生根。

AI能完成的，不过是0到0.5的铺垫——而这远非最难之处。真正的险峰，在于真实世界中的各种逻辑细节和实际问题，AI在此无能为力，它只能在原本的解决模式之上起到加速作用。

更何况，在创业中有一个能力互补的团队是很重要的：一些OPC创业者所遭遇的资源困境，归根结底，是缺少一支并肩作战的队伍。

# AI与社会

如[[尤里卡时刻/哲学/02. 论平等与贫富差距\|02. 论平等与贫富差距]]中谈到的，世界的贫富差距持续扩大，社会环境是重要推手，而技术进步是其中一个不可忽视的因素。许多人宣称AI带来了“技术平权”，这有一定的道理，例如AI时代软件、硬件、结构都有AI设计了，DIY变得更为容易。

但我更倾向于认为，**每个人所能享有的这种“平权”程度千差万别**：
+ 受过良好教育的人，可以利用AI提升学习与工作的效率；但对一位外卖骑手而言，AI能带来多少实质性的价值？对有学习障碍（如厌学）的孩子，AI究竟是帮助他们跨越障碍，还是另一种形式的危害？
+ 回望互联网发展的历史，数字技术创造的巨大财富，大部分流向了资本家和科技巨头，劳动者分得的不过是蛋糕上薄薄的一层。那么，AI所创造的新价值，又会遵循怎样的分配逻辑？

从哲学层面上来看，AI的发展带来生产力的提高，但是生产关系却没有与之适应、人的素质也没有提升，这带来了各种新生的社会问题。如果说AI是实现共产主义的一个契机，那么进行制度变革与生产关系的调整就是绕不过去的一个环节。

未来，或许大家都不用工作，每个人都能有基本工资，可以追求自己的兴趣与热爱；当然也有另一种可能——醉生梦死的“幸福新世界”。


# 出路

初级白领岗位正被AI快速吞噬，传统教育与时代严重脱节，孩子正一点点失去主体性、真实感和意义感——这样的背景下，出路究竟在哪里？

在上过卢老师的《社会创新创业》课程，以及对支教、AI教育创新的了解之后，我隐约看到一种可能：投身社会企业、公益组织，或尝试社会创业。它们的共同底色，是“利他心”——不是在大厂里做一颗耗尽热情的螺丝钉，而是将目光投向社会的痛处与未来。

超脑AI创始人王佳梁曾言，解决社会问题，或许是下一代孩子唯一真正的驱动力。因为他发现，几乎没有什么能让当下的孩子真正行动起来，唯有“帮助他人”这件事，还能让他们迈出脚步，并收获真实的feedback。

这个世界，仍有太多未被抚平的创口，且日益严峻：环境、病痛、心理、战争……选择这条路，意味着放下对金钱、财富自由与稳定的执念，但换来的，是生命得以安放的意义。

或许，这才是技术洪流中，人之所以为人的最后坚守。
