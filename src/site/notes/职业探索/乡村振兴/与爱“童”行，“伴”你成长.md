# 选题灵感

> [!NOTE] 模拟慈善募款作业要求
> 1. 角色与目标：每组扮演一个真实公益慈善项目的筹款执行官，在课程班级内进行筹款。最终根据班上每位同学“捐款”金额的多少决定三组胜负。
> 2. 项目真实性：所选项目必须是真实的公益慈善项目，且所属组织需具备公信力。
> 3. 形式与时间：每组有10分钟展示时间，可使用PPT、短视频等方式进行路演。
> 4. 禁止行为：不得使用贿赂、威胁、向观众发放物品等不正当手段。
> 5. 观众参与：观众（同学）通过“捐钱”方式投票，决定各组的得款金额。
> 6. 团队标识：各组可自行决定服装，但需要统一标识（如贴纸、A4纸贴在身上等），做到简单清晰。

考虑到自己对乡村振兴这个方向比较感兴趣，就在小组群里提议这个方向，组员也一致同意。去[中国乡村发展基金会的官网](https://www.cfpa.org.cn/project/GNProjectList.aspx?tid=63)找项目，最终选定了“童伴妈妈”这个项目。

后来也了解到最好最快的方式应该是去“支付宝公益”、“腾讯公益”这种平台上去找，顺便能了解到一个公益项目是如何表述来尽可能获得更多捐助的，其实这也算是我第一次接触公益平台了。

# 项目介绍

![[童伴妈妈+项目介绍视频.mp4]]

[“童伴计划”](https://baike.baidu.com/item/%E7%AB%A5%E4%BC%B4%E8%AE%A1%E5%88%92/20827354)是由中国乡村发展基金会（原中国扶贫基金会）于2015年10月发起的面向乡村未成年留守儿童的关爱项目。项目采用“一个人、一个家、一条纽带”模式：

+ 一个人：即本土爱心“童伴妈妈”。她通常扎根在村里，熟悉孩子，也熟悉每个家庭的情况，会定期走访，了解孩子的学习、生活、心理和安全状况，及时发现他们的真实需求。
+ 一个家：即“童伴之家”。它不是普通的活动室，而是孩子们在家庭和学校之外的第三个安全空间。在这里，他们可以读书、游戏、参加安全教育和兴趣活动，也可以获得陪伴、倾听和支持。
+ 一条纽带：即背后的多方联动资源。包括民政、教育、卫生健康、公安、司法、妇联、团委等部门，也包括社会组织、志愿者和爱心力量。

截至2025年，“童伴计划”项目已从四川试点扩展至全国14个省份，覆盖近1900个村（社区），累计服务儿童近90万人，培养近1900名本地女性成为专职“童伴妈妈”。项目累计完成家访超184万次，依托“童伴之家”开展主题活动58.5万余场。

清华大学第三方独立评估指出，童伴妈妈项目效果显著，体现在5个方面：
+ 儿童心理健康水平明显提高；
+ 卫生健康水平得到明显改善；
+ 多元化生活需求得到满足，社会支持体系得到巩固；
+ 安全意识明显提升，安全事故发生风险显著降低；
+ 学习成绩有所提升，教育环境日益改善。

# 社会价值

+ 儿童层面：为乡村儿童提供稳定、专业、持续的关爱保护，改善成长环境，促进身心健康发展；
+ 女性层面：为乡村女性提供就业机会与职业发展路径，助力乡村女性赋能与价值实现；
+ 乡村层面：完善乡村治理体系，激活社区活力，推动乡村振兴与未成年人保护深度融合；
+ 社会层面：创新留守儿童关爱模式，为全国农村儿童保护工作提供可复制、可推广的 “童伴样本”；

非常巧合的是，我们小组6人，有4位都是女生，1位是爸爸，其中2位女生已经有小孩了。

# 无法回避的问题

## 留守困境的本质

一开始选题的时候其实就有困惑：这些留守儿童不是孤儿，他们有原生的家庭，那么“童伴妈妈”的加入是否会对原生家庭产生不利的方面？

答案来自[南方周末的一篇评论](https://www.theinno.org/blog/de85c8cbabe)：

> [!NOTE] 留守儿童的“童伴妈妈”：“做，总比不做好”
> 从10年社区经验中，我们发现留守儿童缺乏的是心灵的陪伴，这个缺乏来源两方面，一方面来自父母在城市打工，物理距离的遥远导致的情感疏离；而另一方面来自与他们父母之间没有有效的沟通。“父母”对他们来说，只是一个名词，是“那个每周电话问我3个问题的人”。
> 
> “童伴计划”通过招聘“妈妈”的方式，填补了留守儿童陪伴上的空白，是挺好的尝试。但这些孩子不是孤儿，他们也有父母。因此在实际过程中，除了需要注意可能会引起孩子困惑以外，还需要注意让他们的父母更意识到自己在养育陪伴孩子上的责任，又或者说意识到孩子有被养育和陪伴的权利，并更有意识地去引导他们有效沟通以及由此开始的内在家庭关系的健康发展。
> 
> **“妈妈”们说：希望“以后会好一点，好到这个职业不再被需要”。**

“童伴妈妈”在工作中，不仅负责陪伴孩子，也会通过一些活动（如节日）来引导孩子和父母之间建立更多的沟通联结。

留守儿童是一个经济发展产生的社会问题，仅仅依靠“童伴计划”项目解决不了，亲妈妈的陪伴，是谁也替代不了的。“童伴计划”项目只能说尽力让这些孩子过得开心一点，对孩子的成长来说，做，总比不做好”。

## “童伴妈妈”是否能持续下去

很多的支教活动都存在一个问题，那就是通过短时间的陪伴给孩子们带去了温暖，但在离别后这些志愿者可能就和这些孩子断了联系，对孩子产生了“二次伤害”。

从[新华报业的一份采访](https://www.xhby.net/content/s65ac55bae4b0f4947270d980.html)来看，“童伴妈妈”项目最主要的困难是长期的持续性，而持续性大多来自资金的困难。[CCTV13新闻采访](https://tv.cctv.cn/2024/01/20/VIDEiM8PXGeGRcXADPSJ7x5h240120.shtml)

![[童伴妈妈的资金问题.mp4]]

“童伴妈妈”项目的资金主要有两个来源：
+ 前期（三年）主要依靠中国乡村发展基金会的资金（5万元/年/点），包括民众、企业、名人的捐赠；
+ 后期则主要靠地方财政的支持，基金会进行逐步退出；

也就是说基金会负责开拓新点、选点考察、给三年资金、教怎么干；三年后慢慢退出，靠地方政府自己出钱运营。一些有能力的地方在三年后会将童伴项目纳入财政预算，写进政府工作报告，作为工作人员的考核项来落实，由县乡财政长期保障基础运营费用，才解决最基本的持续难题。

# 小组分工

因为这个小组作业准备时间只有一周，所以在如此紧张的期限内如何高效的协作也值得沉淀一下经验。

| 分类      | 事项        | 责任人 | 时间       |
| ------- | --------- | --- | -------- |
| 资料、素材汇总 | 剧本大纲      | A   | 5.12     |
|         | 资料、素材整合   | A   | 5.13     |
| 素材处理    | PPT制作     | B、A | 5.14晚上   |
|         | 插播视频制作    | C   | 5.13晚上   |
| 演讲      | 上半段演讲稿+主持 | D   | 5.13晚上   |
|         | 下半段演讲稿+主持 | E   | 5.13晚上   |
| 形象&后勤   | 服装（下来搜一下） | C   | 5.12中午下单 |
|         | bgm、打印歌词  | C   | 5.15     |
| 会议沟通    | 选题、分工     | 全体  | 5.11晚    |
|         | 线上对稿      | 全体  | 5.15晚上   |
|         | 线下彩排      | 全体  | 5.16课后   |
这样的分工能发挥各位同学的优势：
+ A：善于深度思考、梳理、统筹能力强；
+ B：有审美，PPT制作水平高；
+ C：执行力强，考虑周到，过往活动有负责过采买的工作；
+ D：声音好听，主持有感染力
+ E：有行业论坛主持经验

一开始我把演讲稿全部排给了E、主持给了D，但是后来发现不能这样做：
+ 效率不高，E的前期工作量大，D的后期工作量大；
+ 质量无法闭环，自己讲的内容自己来写，更能提供整体的质量；

讲稿编写、PPT制作都需要收集素材，如果每个人都需要去网上搜资料的话，整体资源就会有浪费，因此A的角色非常重要，所有的资料都由A来找，并且决定了如何组织材料来更好地传达主题。
