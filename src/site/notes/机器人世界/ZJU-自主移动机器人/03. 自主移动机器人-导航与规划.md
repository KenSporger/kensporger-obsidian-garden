# 导航类型

+ 有人工标识的有轨导航，如利用二维码或磁条标识的工业AGV；
+ 有人工标识的无轨导航，例如利用UWB进行自身定位的导航任务；
+ 无人工标识的自然无轨导航，大多SLAM都是以环境感知进行自定位；



# 导航的步骤

![机器人世界/ZJU-自主移动机器人/assets/03. 自主移动机器人-导航与规划/e80fa02b09bf1807e72d1e71e06565c8_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/03.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E5%AF%BC%E8%88%AA%E4%B8%8E%E8%A7%84%E5%88%92/e80fa02b09bf1807e72d1e71e06565c8_MD5.png)

+ **路径规划**：亦称全局规划，给定地图、当前点和目标点，规划一条可通行路径。（只考虑工作空间的约束，不考虑机器人的运动学模型和约束）
+ **避障规划**：亦称局部规划，针对沿全局规划路径行驶中感知到的动态障碍物进行路径调整。
+ **轨迹生成**：根据机器人运动学模型和约束，寻找适当的控制命令，对可行路径进行平滑以得到可行轨迹。
