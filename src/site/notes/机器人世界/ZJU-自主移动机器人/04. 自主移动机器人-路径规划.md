# 基本概念

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/3bfd0a795200c61ee497b1a927fa6252_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/3bfd0a795200c61ee497b1a927fa6252_MD5.png)

+ **工作空间（work space）**：需要考虑机器人的体积和形状，机器人采用位置和偏航角描述。
+ **位形空间（configuration space）**：机器人抽象为一个质点，并以机器人半径膨胀障碍物，在该空间下，不考虑机器人的体积形状、偏航角和非完整运动学约束。
  + 障碍物空间（forbidden space）: 不可通行的位形集合，机器人与障碍物发生碰撞；
  + 自由空间（free space）：可行的位形集合，机器人可以安全移动；

由于现实中的轮式机器人有多种类型，其中有非完整约束的，也有完整约束的，如果针对每一种类型机器人都规定相应的路径规划方法，则会显得过于复杂。因此，**路径规划中都认为机器人是完整约束的，并采用configuration space**，将机器人看作一个点，在自由空间中规划路径。



**路径规划的完备性**：当解存在时，可以在有限的时间内找到解。

**路径规划一般框架**：拓扑连通图构建+最优路径搜索算法

**拓扑连通图构建方法**：基本思路是对连续空间进行离散化，而路径规划器如何影响离散分解则形成了不同的方法。

+ 分辨率完备：对环境进行解析计算（如分析障碍物的顶点）来离散化取点；
  + 行车图法：在环境中辨识一组路径。
  + 单元分解法：区分空闲和占用的单元；
  + 势场法：在空间中加入函数；
+ 概率完备：基于概率随机采样离散化，例如PRM、RRT。

**最优路径搜索方法**：

+ 精确最优：BFS、DFS
+ 近似最优：
  + 启发式：A*、D\*
  + 准启发式：退火、进化、蚁群优化



# 分辨率完备连通图构建



## 行车图法

利用障碍物的几何形状来分解位形空间，得到一组路径。其算法复杂度与障碍物数量和形状相关，而与地图整体大小几乎无关。主要的实现形式有Visibility graph和Voronoi diagram。

+ **Visibility graph**

Visibility graph先是找出所有障碍物的顶点，然后两两连线，并删除经过障碍物的线段。

**优点**：简单，特别适用于较规则的障碍物；

**缺点**：路径过于靠近障碍物，容易发生碰撞；

**改进**：障碍物膨胀半径，但同时可能会造成可行路径消失；在路径规划后修改路径。

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/0002863e6d7a2cdec7c7776858e228f2_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/0002863e6d7a2cdec7c7776858e228f2_MD5.png)



+ **Voronoi diagram**

不同于Visibility graph，Voronoi diagram将障碍物间的中间点作为节点。构建的方法是为2D平面上的点建立距离直方图，存储该点到最近障碍物的距离（某个点到多个障碍物距离相等时，其距离一般是极大值），Visibility graph节点就是由直方图中尖峰点组成的。

**优点**：最大化了机器人与障碍物间的距离。

**缺点**：计算量较大；规划的路径比Visibility graph要长；由于需要测量与多个障碍间的距离，因此需要有长距离探测传感器。

## 单元分解法

将自由空间分成若干区域（单元），以单元为顶点。主要的实现形式有精确单元分解和近似单元分解（栅格表示法、四叉树表示法）。



+ **精确单元分解**

单元边界严格基于障碍物几何形状进行划分，所有单元都是完全free的。

**优点**：机器人不需要考虑它在每个空闲单元中的具体位置，只需考虑如何从一个单元移动到相邻单元；单元数与地图大小无关。

**缺点**：计算效率极大依赖于障碍物的复杂度。

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/1fceb2135198452d2f7bc447d81d30b6_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/1fceb2135198452d2f7bc447d81d30b6_MD5.png)



+ **栅格表示法**

将环境分解成若干大小相同的栅格。

**优点**：与环境中障碍物的复杂度无关。

**缺点**：存储量较大，尤其用于较大地图的时候。

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/d9e527a24821a6e1f76218f0919476dc_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/d9e527a24821a6e1f76218f0919476dc_MD5.png)



+ **四叉树表示法**

对栅格表示法的改进。递归地将环境分为四个大小相等的子区域，直到每个区域所包含的基本元素全为0或全为1。

**优点**：大大减少了空间存储量。

**缺点**：寻找相邻区域需要进行树查询操作。

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/914247be02d9c57237c91cd5577d388c_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/914247be02d9c57237c91cd5577d388c_MD5.png)





## 势场法

规定目标点对机器人产生吸引力，障碍物对机器人产生排斥力，所有力的合成构成机器人的加速度的控制律。

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/eb948e5dcfb340654db47bbdc8a4a136_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/eb948e5dcfb340654db47bbdc8a4a136_MD5.png)

+ **步骤1-构建目标点的吸引势场**

机器人距离目标点越远则受到的吸引力越大，因此我们可以用距离的平方来表征势能，但为了防止距离过远导致吸引力淹没障碍物的斥力，采用了分段计算。

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/97064cce8632deeef72a489d0f5e3c96_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/97064cce8632deeef72a489d0f5e3c96_MD5.png)



+ **步骤2-构建障碍物的排斥势场**

离障碍物越近则斥力越大，当距离大于安全阈值后，障碍物的作用力消失。

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/75e95c1080398e521765a1b0760cc4e0_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/75e95c1080398e521765a1b0760cc4e0_MD5.png)



+ **步骤3-计算场强**

  类比于静电场中电势和场强的关系，前面建立的势场只是一个标量场，通过对其求负梯度，可以得到一个无旋矢量场，也就是环境产生的场强，机器人位于其中，会受到力的作用。

  ![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/50689aa5676413afb590945e1c5c6d50_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/50689aa5676413afb590945e1c5c6d50_MD5.png)

+ **步骤4-计算合力**

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/92908a36ca3a3c20a857adc01335d40b_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/92908a36ca3a3c20a857adc01335d40b_MD5.png)

该合力的方向就是机器人位于位置$\textbf{x}$应当运动的方向，大小可以作为加速度控制量。



**优点**：势场不仅可以作为一种全局路径规划方法，也可以作为实时避障算法，并且同时也构建了机器人的控制律，指出了可行路径，不需要再应用路径搜索算法。

**缺点**：主要的问题是容易陷入局部最小，产生振荡和死锁。如下图，当障碍物离目标点较近时，目标点的吸引力随距离减小而减小，障碍物的斥力随距离减小而增大，导致机器人远离目标点，尔后又由于吸引力的增大和斥力的减小，又向目标点运动，从而产生死锁。

**解决方法**：程序判断是否陷入死锁，如果陷入，则在障碍物间设置虚拟屏障，使其从上方或下方寻找其它可行路径。

## PRM

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/e67289ca58d01751bcaf92cf339ca3f0_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/e67289ca58d01751bcaf92cf339ca3f0_MD5.png)

在应用PRM时，需要考虑以下问题和技巧：

+ **近邻点搜索**：采用[KD树](https://www.jianshu.com/p/abcaaf754f92)方法进行加速。

+ **路径无碰检测**：在一条路径上增量式（从一个端点按固定距离步长取电）或二分法（递归地取子线段中点）取点，判断点是否落在障碍物中。

+ **路径优化**：由于随机采样，通常路径都欠平滑，或者说非最佳，可以借鉴旅行商问题中的优化方法。

+ **非全连通问题**：如图，当环境存在狭窄通道时，存在图非全连通的情况。主要的解决方式是对节点进行困难度表示，并以该困难度作为节点扩张的概率，从而能增加在狭窄通道里的采样频率。

**优点**：简化了对环境的解析计算，可以快速构建得到行车图；尤其适合于高维度的位形空间。

**缺点**：得到路径的可能性与质量依赖于采样次数，并且也很难评估需要的采样次数；路径未考虑机器人执行的可行性。





## RRT



RRT(Rapid-Exploring Random Tree)的**基本思想**：

+ 连通图采用树的形式（即构建的是有向连通图，而PRM所构建的是无向图），以起始点作为树的根节点；
+ 采用在空间中随机采样一个点、找到树中最近节点，并以此生成新节点的方式拓展树；
+ 考虑机器人的运动执行能力；
+ 通过树结构可以直接回溯得到路径（正是由于图是有向的、可回溯的，省去了路径搜索这一后续步骤）；

**基本流程**：

+ 以机器人初始姿态（由于RRT考虑了运动执行，因此节点除了表示位置信息，还可以表示偏航角）为$q_{init}$为根节点，建立树；
+ 循环以下步骤，完成树的扩张：
  + 在状态空间，随机采样一个位姿状态$q_{rand}$，用于引导树的扩张；
  + 在现有树上查找与$q_{rand}$距离最近的节点$q_{near}$，以$q_{near}$和$q_{rand}$构造控制指令$u$，以$q_{near}$作为当前状态$x$，根据状态转移方程$\hat{x}=f(x,u)$，得到树的扩张节点$q_{new}$；
  + 对$q_{new}$进行碰撞检测，如果安全，则将$q_{new}$加入到树中实现扩张；
  + 如果$q_{new}$非常接近规划目标点$q_{goal}$，则结束扩张，返回Success；如果树的规模达到上限，认为没有可行路径，返回Fail；若以上条件皆不满足，则继续循环扩张；
+ 如果收到Success，通过回溯返回$q_{init}$到$q_{goal}$的路径；

**问题和改进**：

+ 随机状态采样导致扩展是向各个方向进行的，向目标点收敛的效率较低。一个有效的改进是使用双向搜索RRT，即分别以起始点和目标点作为根节点建立两个扩张树，判断它们在扩张过程中是否能建立连接。
+ 利用KD树来加速寻找在树中与随机采样点距离最近的节点
+ 随机性小步扩展导致路径曲折，代价大，改进方法是RRT*：RRT\*算法是渐进优化的，也就是随着迭代次数的增加，得出的路径是越来越优化的。其基本思想是：每当生成了一个新节点$q_{new}$后，是否可以通过将$q_{new}$挂接到邻域其他节点上、将邻域节点挂接到$q_{new}$上来使得路径到$q_{init}$的代价减小。具体的原理参考：https://zhuanlan.zhihu.com/p/51087819



# 分辨率完备和概率完备对比

+ 分辨率完备是基于对环境的解析计算来对连续空间进行离散的；概率完备则是基于随机采样进行离散化；
+ 分辨率完备完全表达了自由空间的连通性；概率完备是指近似表达了连通性；
+ 在可行路径客观存在的情况下，分辨率完备可以确保获得可行解，但是概率完备获得可行解的概率只是趋近于1；
+ 一般来说，分辨率完备的计算量较大，而概率完备计算较快；





# A*寻路算法

参考：[Wiki](https://en.wikipedia.org/wiki/A*_search_algorithm)、http://theory.stanford.edu/~amitp/GameProgramming/



## 算法流程



A*算法是对Dijkstra算法的一个改进，加入了启发函数h(n)，路径的总代价f(n)=g(n)+h(n)，其中g(n)是起始点到当前节点已确定路径的代价，h(n)是当前点到终止节点代价的估计，起到引导扩张的作用，通常选择欧式距离、曼哈顿距离、对角距离或自定义距离函数等。

算法的流程图如下，

![机器人世界/ZJU-自主移动机器人/assets/04. 自主移动机器人-路径规划/5d8c6da994a3a8dbfe8f21aef2c66b84_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/04.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E8%B7%AF%E5%BE%84%E8%A7%84%E5%88%92/5d8c6da994a3a8dbfe8f21aef2c66b84_MD5.png)

首先，算法初始化g(n)和f(n)为无穷大，节点有三种状态：未收录、处于OpenList集合、处于CloseList集合。OpenList是一个优先级队列，每次弹出f(n)最小的节点，加入到CloseList集合中，并遍历弹出节点的邻节点，在一定条件下对每个邻节点的g(n)和f(n)进行更新，并加入到OpenList集合中。当OpenList集合为空或者弹出节点为终止节点时，算法结束。算法的伪代码如下，

```matlab
function reconstruct_path(cameFrom, current)
    total_path := {current}
    while current in cameFrom.Keys:
        current := cameFrom[current]
        total_path.prepend(current)
    return total_path

// A* finds a path from start to goal.
// h is the heuristic function. h(n) estimates the cost to reach goal from node n.
function A_Star(start, goal, h)
    // The set of discovered nodes that may need to be (re-)expanded.
    // Initially, only the start node is known.
    // This is usually implemented as a min-heap or priority queue rather than a hash-set.
    openSet := {start}

    // For node n, cameFrom[n] is the node immediately preceding it on the cheapest path from start
    // to n currently known.
    cameFrom := an empty map

    // For node n, gScore[n] is the cost of the cheapest path from start to n currently known.
    gScore := map with default value of Infinity
    gScore[start] := 0

    // For node n, fScore[n] := gScore[n] + h(n). fScore[n] represents our current best guess as to
    // how short a path from start to finish can be if it goes through n.
    fScore := map with default value of Infinity
    fScore[start] := h(start)

    while openSet is not empty
        // This operation can occur in O(1) time if openSet is a min-heap or a priority queue
        current := the node in openSet having the lowest fScore[] value
        if current = goal
            return reconstruct_path(cameFrom, current)

        openSet.Remove(current)
        for each neighbor of current
            // d(current,neighbor) is the weight of the edge from current to neighbor
            // tentative_gScore is the distance from start to the neighbor through current
            tentative_gScore := gScore[current] + d(current, neighbor)
            if tentative_gScore < gScore[neighbor]
                // This path to neighbor is better than any previous one. Record it!
                cameFrom[neighbor] := current
                gScore[neighbor] := tentative_gScore
                fScore[neighbor] := gScore[neighbor] + h(neighbor)
                if neighbor not in openSet
                    openSet.add(neighbor)

    // Open set is empty but goal was never reached
    return failure
```



## 启发函数的选择

A*算法在一定条件下可以保证所得路径最优：**启发函数估计的代价必须小于等于实际路径代价**。一个实例如下，

![image-20210213180623308](../../.config/Typora/typora-user-images/image-20210213180623308.png)

左图启发函数对代价作了过高的估计，C节点从OpenList中弹出后，将终止点D加入OpenList队列中，由于D的f=g=5，小于B节点代价，因此直接弹出，算法只找到了局部解。

右图，h=1、h=3都要小于等于实际代价3，终止点D加入OpenList队列中后，因此D的f=5，B的f=4，因此先被弹出的是节点B，即算法可以找到最优路径。

通常有多种的启发式函数可供选择，应当根据据工程问题选择满足最优性条件的、更接近真实代价的函数。一般来说，**估计代价越接近真实代价，可以减少扩张范围**，提升算法速度，然而这种提升效果在多障碍物环境中可能并不明显，因为障碍物常常使得路径变得蜿蜒，从而真实代价偏高。

在最优性条件方面，曼哈顿距离只有在四方向移动时才能满足，而欧式距离、对角距离则普遍满足。经验指明，在允许四方向移动的栅格地图上，曼哈顿距离是最佳的选择；在允许八方向移动的栅格地图上，对角距离是最佳的选择；

通过适当变动代价函数f的构成，可以形成其他的算法：f=g时，A*退化为纯粹的Dijkstra算法；f=h时，则是完全的贪心算法；f=g+$\epsilon$h时，称为加权A\*算法，通过改变$\epsilon$的值，可以权衡最优性和速度间的取舍。

OpenList中会有代价相同的节点存在，并且这种情况很普遍，无倾向性地弹出导致过多的扩张。工程中有很多的方法用于缓解该问题，提升算法效率。这些方法的核心思想在于打破路径的对称性：

+ 在f相同时，比较h大小；
+ 略微改变h，有倾向性地从原本f相同的两个节点中进行选择；
