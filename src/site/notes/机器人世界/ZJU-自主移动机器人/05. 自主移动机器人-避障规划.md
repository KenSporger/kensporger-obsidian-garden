主要的避障方法有：Bug算法、势场法、向量势直方图、动态窗口法。

# Bug算法

Bug算法的基本思想是当机器人向目标点（可以是规划的下一个路径点或者最终目标点）移动时，若路径上出现障碍物，则使机器人绕障碍物的轮廓移动，并在合适时机绕离它。不同的绕行方法形成了Bug1和Bug2两种算法。


## Bug1

Bug1中，机器人需要完整绕行障碍物一周，找出离目标最近的轮廓点，然后再绕行至该点，从该点离开障碍物。当动态障碍物是封闭的情况时，可以通过检查绕离点和目标点连线是否无碰来判断路径的存在性。

**优点**：简单，能够获取障碍物轮廓的完整信息，从而确保机器人能够到达任何可达目标。

**缺点**：绕行路径长，效率低。



## Bug2

由于障碍物阻挡了路径，故障碍物轮廓与原路径L应当存在两个及以上的交点，这样，当进入绕行模式时，必然能遇到这些交点，一旦该交点比进入点更接近目标点，就从该交点离开障碍物。当机器人处于封闭障碍物内部时，可以通过判断是否回到最初交点来确定路径的存在性。

# 向量势直方图

论文：[《The vector field histogram-fast obstacle avoidance for mobile robots》](http://www-personal.umich.edu/~johannb/Papers/paper16.pdf)



考虑到势场法仅用推迟势来表示障碍物，丢失了局部障碍物分布的详细信息，VFH算法建立了机器人坐标系下的障碍物概率直方图，用于评估选择最优方向。



+ **步骤1-构建并维护局部栅格地图**

由于机器人传感器直接测量得到的障碍物信息是处于传感器坐标系（机器人坐标系）下的，当机器人运动时，不能直接用来统计。因此需要将每次的传感器数据存储到一个世界坐标系下的局部栅格地图中。如下图所示，根据距离传感器检测数据将相关栅格数值+1，在机器人运动过程中，每一帧都将对栅格值进行叠加。栅格值大小代表了障碍物存在的置信度。

![机器人世界/ZJU-自主移动机器人/assets/05. 自主移动机器人-避障规划/92bf0a8c833b3c85765628f5dbd994a3_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/05.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E9%81%BF%E9%9A%9C%E8%A7%84%E5%88%92/92bf0a8c833b3c85765628f5dbd994a3_MD5.png)



+ **步骤2-计算障碍物向量**

为每个栅格计算其障碍物向量，方向是相对于机器人当前位置的计算的，大小与栅格值和距离有关，距离越近则幅值越大。

![机器人世界/ZJU-自主移动机器人/assets/05. 自主移动机器人-避障规划/23a21c315eddd768d6a85aa8d5793d00_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/05.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E9%81%BF%E9%9A%9C%E8%A7%84%E5%88%92/23a21c315eddd768d6a85aa8d5793d00_MD5.png)



+ **步骤3-计算概率直方图**

按照一定分辨率将0-360度分为n个扇区，每个扇区作为直方图的横轴，统计每个扇区中所有栅格的幅度和，通常最后会对直方图进行平滑去噪。

![机器人世界/ZJU-自主移动机器人/assets/05. 自主移动机器人-避障规划/b32053038a5d90a51f0c8617be0b37f4_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/ZJU-%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA/assets/05.%20%E8%87%AA%E4%B8%BB%E7%A7%BB%E5%8A%A8%E6%9C%BA%E5%99%A8%E4%BA%BA-%E9%81%BF%E9%9A%9C%E8%A7%84%E5%88%92/b32053038a5d90a51f0c8617be0b37f4_MD5.png)



+ **步骤4-方向评估**

根据阈值，筛选出机器人可通过的出口，如果存在多个出口，则分别计算它们的成本，选择最低成本作为避障方向。成本函数中可以考虑出口是否接近目标点、出口方向与当前机器人方向的差异大小等因素。
