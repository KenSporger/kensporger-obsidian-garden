# 机器人的功能类型

+ **操作机器人**：大多是机械臂+末端执行器的形式，模仿人体手臂的功能，完成对物体操作。一般以安装基座作为基础（固定）坐标系，末端可达空间有限。目前较多使用的是六自由度机械臂。

  + 1954年，乔治·德沃尔发明了第一台操作机器人。

    ![[机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/138feb5345dcae8a1ba33e4dbfa3d0be_MD5.png\|机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/138feb5345dcae8a1ba33e4dbfa3d0be_MD5.png]]

  + 应用领域：工业、医疗手术等。

+ **移动机器人**：扩大了机器人的工作范围和活动空间，是本课程所要讲述的对象。

  + 1968年，斯坦福大学推出第一台轮式移动机器人（差分轮式、传感器包括视觉、距离测量、碰撞检测）。

    ![[机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/f3dd3d8192c7065278196731c2ef02ff_MD5.png\|机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/f3dd3d8192c7065278196731c2ef02ff_MD5.png]]

  + 1969年，日本早稻田大学研发了第一台足式移动机器人（当时走一步需要40多秒）。

    ![[机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/375f84e6e5ee3cafb57d610ecb753d8a_MD5.png\|机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/375f84e6e5ee3cafb57d610ecb753d8a_MD5.png]]

    

  + 应用领域：工业、空间探测、家庭服务等。

+ **移动作业机器人**：将移动平台和机械臂（即前两种机器）结合起来。





# 移动机器人运动方式



## 轮式机器人

​	轮式的主要组成：车体、车轮、支撑结构、车轮驱动机构。其中支撑结构主要作用是分散重量、减轻车轮震动对车体的影响、在不平整地面上确保车轮着地。

![[机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/9e2740f67ab64105de8d7c0e99908d6d_MD5.png\|机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/9e2740f67ab64105de8d7c0e99908d6d_MD5.png]]



​	支撑结构的主要类型有非独立悬挂和独立悬挂。

+ 非独立悬挂：其中一个轮子的倾斜会影响其他轮子。
+ 独立悬挂：其中一个轮子的倾斜不会影响其他轮子。

![[机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/6adeade9b9b2ca75c03ed164d85bdbcf_MD5.png\|机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/6adeade9b9b2ca75c03ed164d85bdbcf_MD5.png]]



## 履带式机器人

![[机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/2863ff0445cfa9d370b7929907070bbf_MD5.png\|机器人世界/ZJU-自主移动机器人/assets/01. 自主移动机器人-概述/2863ff0445cfa9d370b7929907070bbf_MD5.png]]

+ 驱动轮和诱导轮一起驱动履带循环。
+ 下滚轮用来减少履带下部着地压强的不均匀性。
+ 上滚轮的作用是防止履带下垂。



## 足式机器人

包括双足、四足、六足等。足式机器人是机器人技术研究的重要难题。

+ 腿部关节对于驱动机构的要求高。
+ 自由度高，不易建模。
+ 易受扰动而失稳。



## 其他类型

**躯干式**：以仿生为主要研发趋势，例如蛇形机器人。

**水下机器人**：深海探测载人潜水器HOV、远程遥控水下机器人ROV、自主水下机器人AUV。

# 自主移动系统

​	自主移动机器人系统的一般架构：**感知（环境感知与定位）、决策、导航、执行**。

​	如下图所示，每个模块运作的频率不同（如视觉信息获取和运动控制运行速度不同），如果采用顺序循环的方式，模块间会存在大量的等待；因此实际运行时通常采用话题订阅发布的模式，使得各个模块可以独立运行。
