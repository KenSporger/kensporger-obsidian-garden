# DDS通信

在ROS1中，节点的注册、话题、服务建立连接都依赖[[机器人世界/ROS小车项目/01. ROS1架构学习#^186cbe\|Master]]的存在，而在ROS2中，由于DDS通信框架的引入，带来了几大好处：
+ 摆脱了节点通信队Master的强依赖，从星型拓扑演化为网状拓扑；
+ 在局域网中的任意两个节点可以自发现并传输消息；
+ 运行制定服务质量QoS；
+ 可以通过共享内存实现零拷贝；

在消息即使性与可靠性的取舍上，ROS2可配置的机制包括：共享内存（iceoryx/FastDDS）、Qos、消息序列化、消息历史保存机制、UDP（话题默认UDP）和TCP。
