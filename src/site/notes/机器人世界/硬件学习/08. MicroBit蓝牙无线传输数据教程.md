# 一、这份教程适合谁？

在开始之前，先确认一下你已经具备以下三个条件：

1. 已经学会了micro:bit连接电脑，并通过MakeCode平台下载代码到micro:bit；

2. 大致掌握了MakeCode图形化编程中的一些基本控件；

3. 想要把micro:bit上传感器的数据、变量的值通过无线的方式传输到电脑（HTML网页）上。

# 三、蓝牙数据接收

## 2\.1  编写蓝牙串口助手

让AI编写一个HTML网页，用于测试接收蓝牙串口传输过来的数据。

```JavaScript
实现一个蓝牙串口助手，接收microbit蓝牙发送的数字并展示，microbit设备已经在系统的蓝牙设置中连接好了
```

[index\.html](index.html)

也可以直接下载上面这个html文件，拖到workbuddy中，告诉AI:


# 四、遗存问题

1. 每一次重启micro:bit，在HTML端都要重新连设备。

2. 如果电脑已经连接了micro:bit蓝牙，可能HTML端会搜不到micro:bit蓝牙，需要系统蓝牙设置先断开/忽略/忘记设备。
