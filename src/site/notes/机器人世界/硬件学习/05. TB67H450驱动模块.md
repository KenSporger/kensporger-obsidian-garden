# H-Bridge

![机器人世界/硬件学习/assets/05. TB67H450驱动模块/b50f7482000aec6c0c0821e84f140b9d_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/05.%20TB67H450%E9%A9%B1%E5%8A%A8%E6%A8%A1%E5%9D%97/b50f7482000aec6c0c0821e84f140b9d_MD5.png)

H桥电路由4个[[机器人世界/硬件学习/04. 模拟电路#^312b15\|NMOS]]组成，通过控制四个MOS管的栅极输入来控制电机的启停、方向以及制动等等。

当Q1、Q4的两个MOS管导通，另外两个MOS管断开，实现电机正转；反之反转。当四个MOS管都断开，电机会依靠惯性继续转动直至停止[[#^d815b1]]；当Q2、Q4两个MOS管打开，上面两个MOS管关闭，能够让电机克服惯性快速停止（转子的惯性会让线圈切割磁感线，两端产生电压差，通过Q2、Q4打开形成闭合回路，电流能顺畅流动，产生的反向磁场能迫使转子停下）。[[#^41d0b6]]

需要注意的是，不能让Q1、Q2或者Q3、Q4同时导通（在快速切换正反转的时候可能瞬间存在这种情况），否则会短路。但使用TB67H450芯片的话，已经做了短路保护，就不需要考虑这个。[[#^45fd4f]]。

另外，H桥如果用NMOS做，高端的两个MOS管源极接VCC就会有[[机器人世界/硬件学习/04. 模拟电路#^e8c265\|04. 模拟电路#^e8c265]]说的问题存在，必须保证栅极电压要在VM+3V的水平[[#^45fd4f]]。那之所以不用PMOS的原因是：
+ PMOS 面积大、成本高
+ 导通内阻大、发热严重
+ 高压大功率工艺不友好
考虑到这些，大部分的驱动芯片都会使用NMOS+[[#^e008f8|电荷泵]]的方式来做。

# 输入信号处理

在电机驱动系统中，`IN1/IN2`这种逻辑输入线，会收到各种干扰（如电容 / 电感耦合产生尖峰噪声），如果直接给到H桥，就会导致控制信号误判，导致电机突然反向。

因此该芯片在输入端接了：
+ **下拉电阻**：用来给悬空的输入引脚提供默认低电平，防止误触发。
+ **施密特触发器**（迟滞比较器）：进一步滤掉输入电平小幅低频抖动、对RC滤波后产生的慢边沿重新整形成边沿陡峭、无抖动的标准方波。[[#^6ecbf5]]

+ VCC Regulator（内部稳压器）：从高压电机电源VM中稳压，为芯片内部的低压电路（控制逻辑、预驱动、保护模块）提供稳定的低压电源（典型值为 5V）。[[#^7ae5a0]]

# Control Logic

控制逻辑模块是纯数字逻辑电路，主要功能：
+ 把简单的 2 路输入，变成 H 桥需要的4 路栅极控制指令（U1、U2、L1、L2）；
+ 安全时序控制，包括上下管切换时的强制delay、斩波时序等等；
+ 电路保护：包括
	+ UVLO：欠压锁定，检测`VCC`或`VM`电压，低于阈值时强制关断H桥；
	+ ISD：短路检测，检测 H 桥的直通电流或栅极状态，一旦检测到上下管同时导通，立即关断驱动，避免电源短路；
	+ TSD：过热关断，内置温度传感器，当结温超过阈值（典型 150℃）时，强制关断 H 桥，防止热击穿；
	+ Current Comp + RS：输出端稳流；

这里具体对内部稳流实现进行展开。控制逻辑通过RS对输出端电流采样，然后通过Current Comp比较器与参考电压VREF（内部做1/10 固定衰减）进行比较，比较器会输出PWM斩波信号，经过安全时序控制后，变成4 路栅极控制指令。在这样的机制下，**VREF和RS电阻决定输出电流的大小：$I_{out}=\frac{VREF}{RS*10}$**[[#^069de7]]。



# Pre-Driver

控制逻辑模块和PreDiver之间的接口有五路，都是低压数字逻辑信号（0V、5V VCC）：
- **U1_CTL**：高侧左管（OUT1 上管）导通指令
- **U2_CTL**：高侧右管（OUT2 上管）导通指令
- **L1_CTL**：低侧左管（OUT1 下管）导通指令
- **L2_CTL**：低侧右管（OUT2 下管）导通指令
- **SD（Shutdown）**：全局关断信号（最高优先级）
控制逻辑模块已经保证了这些指令的时序安全性。

PreDriver将MOS管导通指令推挽放大成栅极驱动信号（强电流，mA 级）。

# 如何使用

![机器人世界/硬件学习/assets/05. TB67H450驱动模块/974ade8677c2bfc9f34b617d3692f586_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/05.%20TB67H450%E9%A9%B1%E5%8A%A8%E6%A8%A1%E5%9D%97/974ade8677c2bfc9f34b617d3692f586_MD5.png)
[[#^7bb4c8]]
通过拉高或者拉低IN1、IN2电平来控制电机是正转、反转还是紧急制动。

VREF对噪声比较敏感，所以需要给一个RC低通滤波（图中用了二阶）。可以用PWM作为输入（频率过低可能会有纹波噪声和啸叫问题[[机器人世界/硬件学习/03. 音圈电机#^aa702d\|03. 音圈电机#^aa702d]]），也可以直接用DAC引脚[[#^658b9b]]输出（数量有限）。

PWM脉冲调制是实现斩波（反复快速开关）的最常用手段，能够实现降压、升压，从而对电机进行调速。当然通过串联一个电位器也能实现降压，但是会有额外的能量损耗。[[#^deb922]]
