+ **旋转关节**：**电机+减速器**，让机器人部位做旋转运动；
+ **线性关节**：**电机+丝杠**， 让机器人部位做直线运动；
+ **灵巧手**
这三种关节占整机硬件成本的一半以上，以特斯拉机器人为例，一共用了14个线性关节、14个旋转关节、12个手部关节。

# 电机

![77df27575e37eefc6db8ab1e7105a8a6_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/77df27575e37eefc6db8ab1e7105a8a6_MD5.png)

电机由**定子**（固定的部分，Magnet）、**转子**（旋转的部分）组成。定子和转子都缠绕上了线圈，通电后，两者产生磁场形成反作用力，从而让转子旋转起来。

电机的分类很多：
+ 直流 永磁 无刷 伺服电机
+ 交流 永磁 同步 伺服电机

![d9891141a1aaacd9dfb023e9efd3b2e2_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/d9891141a1aaacd9dfb023e9efd3b2e2_MD5.png)

## 有刷直流电机

![feb9b50d92860ba2a13f9cc83d9544f0_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/feb9b50d92860ba2a13f9cc83d9544f0_MD5.png)
电机通电产生磁场排斥力后，转子旋转一周，这个排斥力就会消失，两个磁场产生吸引力。这个时候可以通过改变直流电流方向能够让电机接着转动，但是实际电路系统中电流方向是固定的。所以直流电机是靠**电刷+换向器**来实现持续旋转的，具体流程是：电刷接触换向器铜片接通电路产生磁场，电刷接触换向器上的缝隙时，断电磁场消失，转子依靠惯性继续旋转。
![c8f4c390fb947f33cafe207e5c1c5675_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/c8f4c390fb947f33cafe207e5c1c5675_MD5.png)
![658e537b131d9b0ff22432656c184b7a_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/658e537b131d9b0ff22432656c184b7a_MD5.png)

**特点**：定子磁场恒定+转子磁场变化。
**缺点**：电刷和铜片有磨损，会有噪音，寿命短，高速下有火花。


## 直流永磁无刷电机

![8ff9f0e62932c3d655c42f3af487efa3_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/8ff9f0e62932c3d655c42f3af487efa3_MD5.png)

和有刷电机相反。**特点**：转子磁场恒定+定子磁场变化。

转子直接改为永磁体，定子采用三组线圈缠绕，通过控制三组线圈的电流变化从而控制三个方向的磁场变化，推动电机不断旋转。

![8864b2bb76d6b919f9f6c62fab8e3896_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/8864b2bb76d6b919f9f6c62fab8e3896_MD5.png)

## [交流电机](https://www.bilibili.com/video/BV1WMjEzmELy/?share_source=copy_web&vd_source=b1e9d90375317ee28de624f2366c389f)

![fb3aedc98b4c3ec4c2d3aad081eab459_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/fb3aedc98b4c3ec4c2d3aad081eab459_MD5.png)

交流电机的定子和直流无刷电机相似，也是缠绕三组线圈，每个线圈的电流相位相差120度，形成一个旋转的磁场，带动转子旋转。

+ **异步电机**：异步电机的转子和直流电机不同，既不是永磁体，也没有缠绕线圈，而是一个仓鼠笼子的形状。定子磁场使得转子产生感应电流，这个感应电流产生与定子相反的磁场，从而推动转子旋转。转子转速和旋转磁场速度永远不相等，不然就不会产生感应电流了，这也导致异步电机的速度无法精准控制。
+ **同步电机**：在异步电机的基础上，通过加入外部恒定电源、把转子改为永磁体等方式，让转子转速和定子磁场同步，达到速度上更精准的控制。

**异步电机缺点/同步电机优点**：
+ 速度精度差
+ 负载增大会导致转速降低，而同步电机在一定的负载程度下转速稳定（一旦超过阈值会直接停转）
+ 电利用效率低，同步电机的功率因数接近于1
**异步电机优点/同步电机缺点**：
+ 成本低（近几年这个差距在被拉平，大部分还是会用同步电机），转子在高温下不会退磁。


## 伺服电机

**伺服电机**是在电机的基础上增加一个控制系统，包括驱动器、传感器、编码器等部件，可以监测转子状态，达到闭环控制。

## 其他电机

+ **空心杯电机**：是一种直流永磁无刷电机，优势在于重量体积小，转动惯量小，适合用在手部的旋转关节。  ![dfe6958efd401e53efeb8b5ad401c5b8_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/dfe6958efd401e53efeb8b5ad401c5b8_MD5.png)
+ **无框电机**：没有传统机械外壳的电机，定子和转子是环状的，可以用来镶嵌，拥有更紧凑的尺寸，适合有限的机器人内部空间。

# 减速器

电机是**高转速、低扭矩**，一般在电钻、无人机上运用，但是要用电机直接连接机械臂举起重物，就比较困难了。**减速器**就是一个**齿轮组**，将输入轴的高转速低扭矩转化为输出轴的低转速高扭矩。所谓的减速减小的就是齿轮的转速，汽车的变速箱也是这个道理。

![5ff4cd5e679481c32f327316a9784e9f_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/5ff4cd5e679481c32f327316a9784e9f_MD5.png)

## 行星减速器

![d7ca85493e9bce14e17cc1cb621c0e49_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/d7ca85493e9bce14e17cc1cb621c0e49_MD5.png)

齿轮组的构造是输入轴在中间，三个齿轮围绕旋转带动外层最大齿轮转动。这种结构质量体积小，一般用在手部与空心杯电机组合。

**缺点**：传动比比较低（不超过10:1）。

## 谐波减速器

![7692e9fb39a3009ffe32a2315b59df7e_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/7692e9fb39a3009ffe32a2315b59df7e_MD5.png)

由波发生器、柔轮、钢轮组成。齿轮啮齿不完全咬合，通过波完成传动。

**优点**：传动比大（几百:1）

## RV减速器

由行星减速器完成第一次减速，然后再由摆线针轮减速器完成第二次减速。

**优点**：
+ 有限空间内实现更大的减速比。
+ 将扭矩分配到更多齿轮和传动元件上，减少每个元件承受的负载，提高系统的可靠性和寿命。

RV减速器的制造工艺十分精密，目前还是依赖进口，价格较高。

![e8a25e2b3f6a045b552e7facc6608b5e_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/01.%20%E4%BA%BA%E5%BD%A2%E5%85%B3%E8%8A%82/e8a25e2b3f6a045b552e7facc6608b5e_MD5.png)

## 滚珠丝杠

# 案例

机器人不同部位采用不同类型的旋转关节（需要综合性能与成本），即由不同类型的电机和减速器组合完成。
+ 腰部、大腿：需要较大负荷能力，需要较大扭矩的旋转关节，例如采用无框电机+谐波减速器+编码器伺服。
+ 手部：需要灵活和快速响应、体积小的旋转关节，例如空心杯电机+多级行星减速器。

从大疆机场这个产品中，也能看到这些关节的应用：
+ 无人机螺旋桨：直流永磁无刷电机；
+ 机场1舱盖：无框电机+行星减速器（可能吧）；
+ 机场1停机坪：滑动丝杠（齿轮带）；

# 技术特性分析

分析大疆无人机直刷电机与人形机器人的执行器在技术特性要求方面的差异。
+ **寿命**：无人机电机寿命要求是千小时级，人形机器人是万小时级（更换麻烦、工况损耗大、持续工作场景）；
+ **过载可靠性**：无人机电机对短时过载峰值功率与响应速度有更高要求（对抗阵风），人形机器人需要持续的重载、高扭矩保持；
+ **热可靠性**：无人机和人形机器人都对电机耐高温和散热有较高要求，前者由于高空作业散热条件好，后者电机在密闭关节腔，散热差；
+ **抗振/抗冲击可靠性**：无人机作业有高频振动，对轴承、整机固定件的抗共振有较高要求；人形机器人则关注对抗冲击，减速器零件抗扭矩；
+ **控制精度**：无人机需要精准控制转速差，人形机器人主要是控力矩大小；
+ **环境可靠性**：无人机面对的是严苛的自然环境（风雨、盐雾、沙尘），人形机器人面对的是复杂的结构化环境（楼梯、窄道、门窗、人群），前者对于电机的IP防护上有更高要求；
+ **故障容错**：无人机单电机失效可尝试快速切断或依靠多旋翼冗余降落，人形机器人发生关节电机故障需要安全停机抱闸（防止重力下坠）；
