# 二级管[[#^ba4f1b]]

![机器人世界/硬件学习/assets/04. 模拟电路/a123a1c4b9d8b3b816a13e79a0771707_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/a123a1c4b9d8b3b816a13e79a0771707_MD5.png)

通过对硅参杂不同的元素，形成了**P型半导体**（参杂硼等）、**N型半导体**（参杂磷等），他们结合处的**PN结**具有**单向导通性**：
+ 电流从P流向N，绝缘区域消失，导通；
+ 电流从N反向流向P，内部将产生大量绝缘区域，阻止电流通过；

# 三极管[[#^ba4f1b]]

![机器人世界/硬件学习/assets/04. 模拟电路/6e26cc8db08e2740b52ffb4e5e759586_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/6e26cc8db08e2740b52ffb4e5e759586_MD5.png)

通过在P型半导体施加小电流，能使得N1->N2的大电流导通（P做得非常薄，所以P通过电流后就像消失了一样），实现**小电流控制大电流**的效果，就像水龙头一样。

![机器人世界/硬件学习/assets/04. 模拟电路/d6e8c5f30c250348148f54e1a28722d3_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/d6e8c5f30c250348148f54e1a28722d3_MD5.png)

三极管分为**NPN型、PNP型**。PNP型的小电流使从**发射极e**流向**基极b**的，使得发射极到**集电极c**的大电流通过。

![机器人世界/硬件学习/assets/04. 模拟电路/51e57566e45dcb09418462fa02e7a599_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/51e57566e45dcb09418462fa02e7a599_MD5.png)

# JEFT管[[#^ba4f1b]]

二级管和三极管组成了最早的集成电路芯片，实现了开关、放大等功能。但随着对集成电路密度要求的提高（尤其是微型计算机出现后），三极管暴露了一些致命缺陷：
+ 通过的大电流有限，收到PN结的物理限制（要增大PN结面试，使得器件体积变大）；
+ 电流通过PN结，此过程产生发热损耗；
+ 只能电流控制，无法电压控制；

![a3f78b26111a794e1f957a88a7a92df4_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/a3f78b26111a794e1f957a88a7a92df4_MD5.png)

于是，贝尔实验室的科学家设计了一种新的**JFET（PN结场效应管）结构**：利用**PN结反向电压越大，绝缘区域越宽**的特性，在N型半导体的两次防止P型半导体，当N型半导体施加大电压时，两侧PN结绝缘区域增大直至结合在一起，阻止N型半导体电流通过。而如果将P型半导体上的负电压断开，绝缘区消失，电流导通（并且没有PN结损耗）。

![机器人世界/硬件学习/assets/04. 模拟电路/a36824a77d7a5f75fb86a308b4c7c566_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/a36824a77d7a5f75fb86a308b4c7c566_MD5.png)

但是JFET管的缺点是PN结绝缘区域可能夹不紧，会有一些小电流漏出，对于一些需要完全断开的开关电路是不能接受的。

# MOS管[[#^ba4f1b]]
{ #312b15}


为了解决JFET管的缺点，需要进一步改进半导体结构，最好使得：**初始无电压是断开状态，加电压后导通**。因此，利用**电容的场效应**，设计了出了**MOS管**：当G->S施加正电压，会使得P型半导体上方聚拢大量电子，使得两侧N型半导体连通，可通过大电流；当施加的电压消失，电子会分散，两侧N型半导体的桥接通道断开。这个过程类似于在河上架桥。 

![941ed6cedf44e4d094438ac41d12f096_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/941ed6cedf44e4d094438ac41d12f096_MD5.png)

MOS管也分为NMOS和PMOS管。
 ![机器人世界/硬件学习/assets/04. 模拟电路/77f38e9781e0d6c61a9746fc933cffe6_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/77f38e9781e0d6c61a9746fc933cffe6_MD5.png)

## 开关电路

### NMOS[[#^48aaed]]

![机器人世界/硬件学习/assets/04. 模拟电路/3c8d177d33f163b93c08ab7cac77b542_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/3c8d177d33f163b93c08ab7cac77b542_MD5.png)

开关电路中，栅极G端不能悬空，必须接地，并放一个下偏置电阻，防止G端高压静电将二氧化硅绝缘层击穿。

![机器人世界/硬件学习/assets/04. 模拟电路/8fb9c6cb271b1deff013dbd6a1ab4da4_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/8fb9c6cb271b1deff013dbd6a1ab4da4_MD5.png)

其次，对于NMOS开关电路，RL电阻必须放在漏极D端。这是因为要使MOS导通，$V_{GS}$必须始终满足栅极阈值电压（上图为1.2V），那么如果将电阻接在S端，一开始$V_{GS}=4.95V$可以导通，但导通之后$V_S$上升至10V，会使得$V_{GS}$少于1.2V。
{ #e8c265}


当然也可以在基极施加10V以上电压，但是这可能会超过MOS管的额定$V_{GS}$值，损坏器件。

![机器人世界/硬件学习/assets/04. 模拟电路/18a8723c6d4d93c4647c1364a748f01a_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/18a8723c6d4d93c4647c1364a748f01a_MD5.png)





### PMOS[[#^ba4f1b]]

和NMOS区别在于，G端相对于S端是负电压导通，接上偏置电阻。

![机器人世界/硬件学习/assets/04. 模拟电路/9305bee9b4b379a794a51c5d8cbbe744_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/9305bee9b4b379a794a51c5d8cbbe744_MD5.png)

## 寄生二极管[[#^6f56cd]]

MOS管在漏极PN处有一个寄生二级管，能够保护MOS管在反向电压下不被击穿。

例如在，在驱动电机时，如果电机线圈的电流突然断开，线圈会产生很高的反向感应电动势，很容易击穿 MOS 管。而寄生二级管能给这个反激电流提供一个安全的泄放回路。

![机器人世界/硬件学习/assets/04. 模拟电路/c94080ca191bbbc2b564c294c7abfee3_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/04.%20%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF/c94080ca191bbbc2b564c294c7abfee3_MD5.png)
