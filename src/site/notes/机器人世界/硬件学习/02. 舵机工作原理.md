舵机是一种位置（角度）伺服驱动器，通过闭环控制系统，将电信号转化为精确的机械动作，实现输出轴角度的定位与保持。‌

# 分类

- **角度舵机**：最常见类型，转动角度受限（如 0°-180°），定位后能稳定保持角度（依靠角度闭环负反馈 + 减速齿轮增扭 + PID 动态力矩补偿），适用于机械臂关节、航模舵面控制。
- **连续旋转舵机**：无角度限制，可 360°连续转动，通过脉冲宽度控制转速和方向，类似可控速电机，常用于机器人车轮驱动。
- **线性舵机**：将旋转运动转化为直线推拉动作，控制推杆伸缩距离，适用于自动门锁、夹爪开合等场景。

# 参数

![机器人世界/硬件学习/assets/02. 舵机工作原理/063b2e4f7ccdf0b5d86bd22dd6cc9549_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/02.%20%E8%88%B5%E6%9C%BA%E5%B7%A5%E4%BD%9C%E5%8E%9F%E7%90%86/063b2e4f7ccdf0b5d86bd22dd6cc9549_MD5.png)

- **扭矩**：衡量带负载能力，单位通常为 kg·cm 或 N·m，负载越重需选择扭矩越大的舵机。如上图所示，标识的9g和25kg都是指距离轴1cm的地方额定施加的最大重量（2cm则变为12.5kg，3cm变为6.25kg，即每增加1cm负载能力减半）；
- **转速**：表示输出轴转动一定角度所需时间，单位常用 sec/60°，数值越小转动越快。
- **工作电压**：多数舵机工作电压为 4.8V-6V，电压过高可能烧毁电路，需匹配供电设备。


# 原理

![机器人世界/硬件学习/assets/02. 舵机工作原理/f9496a0ac56f8703f831d0b77276b31e_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/02.%20%E8%88%B5%E6%9C%BA%E5%B7%A5%E4%BD%9C%E5%8E%9F%E7%90%86/f9496a0ac56f8703f831d0b77276b31e_MD5.png)

直流电机作为减速齿轮组的输入，降低转速，提高扭矩。

![6033db171f17e4e12cb7858d08a9e2b4_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/02.%20%E8%88%B5%E6%9C%BA%E5%B7%A5%E4%BD%9C%E5%8E%9F%E7%90%86/6033db171f17e4e12cb7858d08a9e2b4_MD5.png)

最后一节齿轮会带动一个电位计转动（可变电阻器），在不同角度下对应不同电阻，控制板根据这个电阻来获取当前角度。

![机器人世界/硬件学习/assets/02. 舵机工作原理/629f5475cb4c9baf16de63cee31f1445_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E7%A1%AC%E4%BB%B6%E5%AD%A6%E4%B9%A0/assets/02.%20%E8%88%B5%E6%9C%BA%E5%B7%A5%E4%BD%9C%E5%8E%9F%E7%90%86/629f5475cb4c9baf16de63cee31f1445_MD5.png)

一个舵机通常有三个输入线：GND、VCC和PWM信号输入。通过输入周期固定宽度不同的PWM信号，能够控制舵机转到指定角度。

具体的内部实现是：输入的PWM经过主控芯片（Converter）捕获 PWM 高电平持续时间，计算出目标角度；电位器采集当前的角度，并和主控输出电压进行比较（Comparator）得到误差；主控板根据误差输出电平信号给 H 桥驱动电路（Motor Driver），进行功率放大，控制电机正转、反转、慢速微调、刹车等；到达目标角度后，误差接近0，主控通过PID输出微小维持电流，使得电机持续输出一个反向力矩，和外部负载力矩动态平衡。
