# ROS1与ROS2的参数差异

ROS1 和 ROS2 在**参数系统**和**节点注册**上有**架构级差异**：
+ ROS1：采用**全局参数服务器**，参数无隔离、无需声明、类型不安全；
+ ROS2：基于**节点本地参数**（强隔离），**必须显式声明参数**、类型安全、原生支持回调 / 约束。


# ROS2参数示例

一般在Node的构造函数中申明和初始化：
```cpp
#include <rclcpp/rclcpp.hpp>
#include <rcl_interfaces/msg/parameter_descriptor.hpp>

class TestNode : public rclcpp::Node {
public:
    TestNode() : Node("test_node") { 
        // 声明字符串参数：参数名 + 默认值 + 描述
        rcl_interfaces::msg::ParameterDescriptor desc;
        desc.description = "test_description";
        this->declare_parameter<std::string>("topic", "test_topic", desc);
        // 声明int参数 + 数值范围约束（高级特性）
        auto speed_desc = rcl_interfaces::msg::ParameterDescriptor().set__integer_range({0, 10});
        this->declare_parameter<int>("speed", 5, speed_desc);
        // 读取已申明的参数（若不存在，会崩溃）
        control_freq_ = this->get_parameter("control_freq").as_double();
        // 读取参数（若不存在，会创建默认值5.0）
        control_freq_ = this->declare_parameter<double>("control_freq", 5.0);
    }
private:
    double control_freq_;
};
```
