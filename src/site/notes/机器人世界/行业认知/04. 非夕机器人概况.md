# 公司

主要关注**自适应机器人**产品，主要技术是工业级力控（**高精度力/力矩传感器与轴定位式关节**）、计算机视觉和人工智能技术。

由浙江大学客席教授王世全成立于2016年，核心团队来自于斯坦福大学。在硅谷、上海、北京、深圳、新加坡、慕尼黑都有办公室，制造工厂在佛山。

2025年获评 **专精特新“小巨人”企业**，并在多个大会有过展出。


# 技术

## 力控

**力控**指的是力矩控制，区别于**位置/速度控制**。两者的对比如下：

| 维度     | 位置 / 速度控制        | 力控算法              |
| ------ | ---------------- | ----------------- |
| 控制核心   | 位姿、速度（几何量）       | 接触力、关节力矩（物理量）     |
| 依赖模型   | 只需要运动学           | 必须运动学 + 精确动力学     |
| 对外力态度  | 当作干扰，强行压制        | 当作被控量，主动维持        |
| 运动规划输出 | 固定位置轨迹 q(t)/X(t) | 力约束下柔顺位姿轨迹 + 力矩指令 |
| 环境适应性  | 差，只能适配固定环境       | 强，适配公差、曲面、人机交互    |
| 典型场景   | 喷涂、搬运、点焊（无接触）    | 装配、打磨、插拔、拖动示教     |
力矩控制能够做到机械臂的**柔性**，也就是当施加外力（人为拖动某个关节），机械臂会顺应着走，但是仍然能使末端维持在目标位置上。这样的力控技术主要依赖**力传感器**、**控制算法**。

## 并联机器人

![[机器人世界/行业认知/assets/04. 非夕机器人概况/5227841aea713d072a2b8734fe297589_MD5.png\|机器人世界/行业认知/assets/04. 非夕机器人概况/5227841aea713d072a2b8734fe297589_MD5.png]]

| 对比项   | 非夕并联机器人                       | 单机械臂（串联）                   |
| ----- | ----------------------------- | -------------------------- |
| 结构特性  | 多支链并联支撑，驱动器固定于基座，**无悬臂效应**    | 串联链式结构，驱动器随关节移动，**悬臂效应明显** |
| 刚度表现  | 刚性提升**5-10 倍**，末端变形量 < 0.01mm | 刚度随臂展增加而下降，末端易变形           |
| 抗干扰能力 | 多链协同抵消外力扰动，力控响应更稳定            | 外力易沿运动链传递放大，抗扰能力弱          |
| 核心价值  | 适合高速、高精度接触作业（如打磨、装配），避免振动与漂移  | 适合非接触、大范围移动作业              |
**悬臂效应**：就像人用一只手去提重物，导致下垂、易变形、振动。

## SDK

为了向专业开发者开放机器人底层能力，支持定制化开发与多场景集成，提供了开发工具包 Flexiv RDK、Flexiv TDK、和 Flexiv DDK。

| 工具包                                                     | 全称                            | 核心定位        | 本质属性                                                                            |
| ------------------------------------------------------- | ----------------------------- | ----------- | ------------------------------------------------------------------------------- |
| [**RDK**](https://github.com/flexivrobotics/flexiv_rdk) | Robotic Development Kit       | 非夕机器人通用开发平台 | 基础 SDK，提供机器人底层控制能力，例如状态获取、运动控制等                                                 |
| [**TDK**](https://github.com/flexivrobotics/flexiv_tdk) | Teleoperation Development Kit | 遥操作软件开发工具包  | 针对一些危险的无法近距离操作的场景，使用一台机械臂作为控制端（主臂），另一台机械臂作为跟随端（从臂）。TDK实现主从臂间高透明度、柔顺稳定的运动跟踪和力反馈。 |
| [**DDK**](https://github.com/flexivrobotics/flexiv_ddk) | Data Distribution Kit         | 数据分发工具包     | 主要用于高效实时采集机器人实时状态数据。                                                            |
