# 基础模型

与[[学术研究/论文笔记/论文10-Foundation Model Driven Robotics-A Comprehensive Review\|论文10-Foundation Model Driven Robotics-A Comprehensive Review]]中的框架相似，将大模型与感知、规划、执行、记忆相结合。

![机器人世界/具身智能/assets/04. 穹彻智能 Noematrix Brain/ffe2876fff9ea27b7ca1c2754add8b0f_MD5.png](/img/user/%E6%9C%BA%E5%99%A8%E4%BA%BA%E4%B8%96%E7%95%8C/%E5%85%B7%E8%BA%AB%E6%99%BA%E8%83%BD/assets/04.%20%E7%A9%B9%E5%BD%BB%E6%99%BA%E8%83%BD%20Noematrix%20Brain/ffe2876fff9ea27b7ca1c2754add8b0f_MD5.png)

+ **实体世界大模型**：主要根据环境信息、对用户指令的语义理解去生成动作序列。
+ **机器人行为大模型**：主要是将世界大模型生成的动作规划转为符合物理约束的底层执行器的控制信号。

相关研究：[https://www.noematrix.ai/research-innovation](https://www.noematrix.ai/research-innovation)


# 原子操作库（AnySkill）

原子操作包括：
+ 对通用（未知）物体抓取；
+ 柔性衣物、毛巾等物体的折叠；
+ 通用物体表面刮削技能，如刮胡子、削皮；
+ 通用物体打开，如冰箱、抽屉；
+ 通用物体舀取；
+ 通用物体整理摆放；
+ ...
