# Recognizing Plagiarism Certificate

## 核心定义

+ **No Plagiarism**（非抄袭）：文中标注作者、日期，文末标注参考文献；
+ **Word-For-Word Plagiarism**（逐字抄袭）：≥7words/换词不换句式，并且没有正确引用（缺少引号、作者、日期，文末标注参考文献）；
+ **Paraphrasing Plagiarism**（改写抄袭）：对原文观点进行总结（缺少正确放置的引用），使得人们无法判断是谁的观点。


## 判断法则

1. ≥7words  (无论是否有reference)ww
2. Highly summarized but no reference  PP
3. Highly summarized ＋reference   NP
4. 复制别人原句，加引号以及文中引用 不算抄袭；Quotation remarks＋Citation ＋reference   NP
